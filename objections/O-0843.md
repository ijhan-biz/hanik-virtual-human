# O-0843 · 사전 라우팅 규칙도 모호성의 선택 효과를 숨길 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2767
- 해소: 반복 2774에서 C-003의 주장·근거·한계에 모호 사례의 라우팅 전 잠재 귀속과 계보 간 공동 지지를 결과 독립 입력으로 열거하고, 라우팅 규칙별 잠재 분모·선택확률·오류 결합의 공동 범위를 독립 대조·자연 계보에서 교차하거나 부분식별하도록 실제 반영했다. 잠재 귀속·공동 지지를 식별하지 못하거나 최악·최선 범위가 결론을 바꾸면 의미 불변성·운반·귀속·계보·연속성을 보류한다.

## 반론

C-003은 공통·고유 오류의 분류와 보정·대조·자연 계보의 채택, 모호 사례 라우팅을 결과
독립 입력과 사전 완전성 기준으로 고정하고, 선택 의존의 잠재 분모·선택확률과 오류 결합별
교환가능성 범위를 독립 대조와 자연 계보에서 교차하거나 부분식별하도록 고쳤다. 그러나
사전 등록된 라우팅 규칙도 관측 가능한 표지와 기준 진실의 불확실성에 따라 모호 사례를
서로 다른 계보에 배정하는 경우, 규칙 자체가 분류 불능·목록 밖 사례를 특정 검증 계보로
선택하는 효과를 가릴 수 있다. 특히 모호 사례의 잠재 귀속이 공통 오류와 결합하면 사전
완전성 기준을 충족한 것처럼 보여도 계보별 선택확률과 오류 결합의 공동 지지가 달라진다.

따라서 라우팅 규칙을 사전 고정하고 계보별 범위를 산출하는 것만으로는 라우팅 전 잠재
귀속과 계보 간 공동 지지를 보장할 수 없다. 모호 사례의 잠재 귀속·분모·선택확률과
오류 결합별 공동 범위를 식별하거나 부분식별하지 못하면 해당 의미 불변성·운반·귀속·
계보·연속성을 확정해서는 안 된다.

## 해소 조건

C-003은 모호 사례의 라우팅 전 잠재 귀속과 계보 간 공동 지지를 결과 독립 입력으로
열거하고, 라우팅 규칙별 계보 잠재 분모·선택확률·오류 결합의 공동 범위를 독립 대조와
자연 계보에서 교차하거나 부분식별해야 한다. 잠재 귀속 또는 공동 지지를 식별하지
못하거나 최악·최선 범위가 결론을 바꾸면 해당 의미 불변성·운반·귀속·계보·연속성을
보류해야 한다.
