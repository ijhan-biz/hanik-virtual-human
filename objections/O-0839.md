# O-0839 · 측정면별 의미 보존의 교환 검정이 공통 오류에 오염될 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2746
- 해소: 반복 2752에서 C-003의 주장·근거·한계에 기준 진실·보정 표본·외부 목록 계보의 공유 오류와 측정면별 고유 오류를 결과 독립 입력으로 분리하고, 공통 오류가 만드는 비편입 분모·선택확률·운반 가중의 상관 구조와 측정면별 교환가능성의 최악·최선 범위를 공통 기준을 공유하지 않는 독립 대조·자연 계보에서 교차하거나 부분식별하도록 실제 반영했다. 공통 오류·보정 의존·목록 계보의 상관을 식별하지 못하거나 범위가 결론을 바꾸면 의미 불변성·운반·귀속·계보·연속성을 보류한다.

## 반론

C-003은 자료별 측정 오류와 분류 민감도·특이도, 목록 갱신 지연을 거친 뒤에도 공통
자격·경계·목록·생성 규칙이 같은 잠재 대상의 의미를 보존하는지 판정하고, 측정면별
비편입 분모·선택확률·운반 가중의 교환가능성을 독립 대조와 자연 계보에서 교차하도록
고쳤다. 그러나 두 측정면이 같은 기준 진실, 보정 표본, 외부 목록의 계보를 공유하면,
그 교환가능성 검정은 양쪽에 같은 오분류와 갱신 누락을 주입한 결과일 수 있다. 공통
오류가 측정면 간 차이를 상쇄하면 관측된 선택확률과 가중은 일치해도 실제 잠재 대상의
의미 보존은 식별되지 않는다.

따라서 측정면별 교환가능성과 최악·최선 범위를 양 자료에서 계산하는 것만으로는 공통
기준 진실 오류·보정 의존·목록 계보의 공유 오염을 배제할 수 없다. 공통 오류의 잠재
분모와 상관 구조를 결과 독립 입력으로 식별하거나 부분식별하지 못하면 해당 의미
불변성·운반·귀속·계보·연속성을 확정해서는 안 된다.

## 해소 조건

C-003은 측정면별 기준 진실·보정 표본·외부 목록 계보가 공유하는 오류와 고유한 오류를
결과 독립 입력으로 분리해 명시해야 한다. 공통 오류가 만드는 비편입 분모·선택확률·
운반 가중의 상관 구조와 측정면별 교환가능성의 최악·최선 범위를 공통 기준을 공유하지
않는 독립 대조·자연 계보에서 교차하거나 부분식별해야 한다. 공통 오류·보정 의존·목록
계보의 상관을 식별하지 못하거나 범위가 결론을 바꾸면 해당 의미 불변성·운반·귀속·
계보·연속성을 보류해야 한다.
