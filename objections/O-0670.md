# O-0670 · 생성 규칙 교환이 후보 우주를 바꾸어 반사실을 식별하지 못할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2027
- 해소: 반복 2032에서 C-003의 주장·근거·한계에 잠재 후보 우주의 단위와 생성기 입력·피드백·자원 상태를 결과 독립 입력으로 사전 고정하고, 생성되지 않은 경로의 잠재 분모를 별도 열거하도록 실제 반영했다. 자연 운영 및 독립 양성·음성·모호 대조에서 동일 우주 내 생성·편입·제거 교환과 우주가 달라지는 교환을 분리해 각 경로의 발견 하한·최악·최선 영향·미식별 잔여를 산출하며, 제3자 재현 실패나 우주 변화 잔여의 결론 변화 시 생성 계보와 의존 연속성을 보류한다.

## 반론

C-003은 후보 생성·편입·제거와 단계·순서·대체를 교환하고 생성 전·후 분모를 나누도록
고쳤다. 그러나 생성기가 부하·자원·앞선 후보의 존재·실패 결과를 입력으로 받아 후보의
종류와 수를 바꾸면, 생성 규칙을 교환하는 순간 편입·제거 순서뿐 아니라 후보 우주 자체가
달라진다. 관측된 후보의 부모·자식 계보를 기록해도 교환되지 않은 생성 경로에서만 생기는
후보와 생성되지 않아 비교할 수 없는 후보의 결과는 복원되지 않는다. 따라서 생성 전
탈락과 생성 후 탈락을 분리한 산출만으로는 동일한 잠재 후보 우주에 대한 단계 교환의
반사실이라고 할 수 없고, 생성 규칙의 변화가 운반 불능 잔여를 결론에 숨길 수 있다.

## 해소 조건

C-003은 생성 규칙을 교환할 때 유지할 잠재 후보 우주의 단위와 생성기 입력·피드백·자원
상태를 결과 독립 입력으로 사전 고정하고, 생성되지 않은 경로의 잠재 분모를 별도 열거해야
한다. 자연 운영 및 독립 양성·음성·모호 대조에서 동일 우주 내 생성·편입·제거 교환과
우주가 달라지는 교환을 분리해 각 경로의 발견 하한·최악·최선 영향·미식별 잔여를 산출해야
한다. 제3자가 잠재 우주와 교환 산출을 재현하지 못하거나 우주 변화 잔여가 결론을 바꾸면
해당 생성 계보와 의존 연속성을 보류해야 한다.
