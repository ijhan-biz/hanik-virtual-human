# O-0737 · 라벨 대응 기준이 공통 측정 오류 아래 잠재 층을 식별하지 못한다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2307
- 해소: 반복 2328에서 C-003에 공통 기준 진실 오류·관측 변환·라벨 재배열 후보를 결과 독립 입력으로 사전 등록하고, 외부 기준 또는 서로 독립된 측정면에서 잠재 층별 불변성의 식별 가능성을 검증하도록 반영함. 양성·음성·모호 대조에서 후보별 공동 잠재 분모·선택·측정 결합·발견 하한·부분식별 범위를 산출하고, 최악·최선 범위가 결론을 바꾸거나 불변성을 식별하지 못하면 해당 층의 외삽·운반·분모·귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 대조와 실제 계보의 잠재 층 표지가 같은 상태·전이·관측·분류 오류를 뜻하는지
결과 독립 측정 불변성 검정과 라벨 대응 기준으로 확인하도록 고쳤다. 그러나 양성·음성·
모호 대조와 실제 계보가 공유하는 기준 진실의 오류나 관측면의 공통 변환은 모든 라벨을
동시에 같은 방식으로 재배열할 수 있다. 이 경우 대응표와 측정 불변성 검정은 결과와 독립적으로
수행되어도 서로 다른 잠재 상태 해석이 같은 관측 라벨을 만들며, 대응 불능 후보를 찾지 못한
채 최악·최선 범위를 과소평가할 수 있다. 따라서 등록된 라벨 대응만으로 잠재 층의 상태·전이
의미가 계보 사이에서 식별된다는 결론은 아직 보장되지 않는다.

## 해소 조건

C-003은 공통 기준 진실 오류·관측 변환·라벨 재배열의 후보를 결과 독립 입력으로 사전
등록하고, 외부 기준 또는 서로 독립된 측정면에서 잠재 층별 불변성의 식별 가능성을 검증해야
한다. 양성·음성·모호 대조에서 공통 오류를 포함한 대응 후보별 공동 잠재 분모·선택·측정
결합·발견 하한·부분식별 범위를 산출하고, 어떤 후보의 최악·최선 범위가 결론을 바꾸거나
불변성을 식별하지 못하면 해당 층의 외삽·운반·분모·귀속·계보·연속성을 보류해야 한다.
