# O-0773 · 공동 결합 estimand이 다중 부모의 시간적 귀속을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2485
- 해소: 반복 2505에서 C-003에 공동 지지를 만족하는 부모 조합마다 순서·재진입·공유 후속의 원자화와 시간창을 결과 독립 입력으로 사전 등록하고, 독립 양성·음성·모호 대조와 자연 계보에서 동일한 공동 관측을 만드는 선후·동시·중간 전이·직렬화 대안을 교차하도록 실제 반영했다. 대안별 시간적 귀속 가능 집합·공동 잠재 분모·조건부·결합 estimand·발견 하한·부분식별 범위를 산출하고, 대조가 대안을 재현하지 못하거나 순서·중간 전이를 식별하지 못하거나 범위가 결론을 바꾸면 해당 다중 부모 귀속·계보·연속성을 보류하도록 했다.

## 반론

C-003은 부모 조합의 공동 지지·공동 잠재 분모와 교차세계 의존 구조를 등록하고, 공동
선택확률과 결합 estimand의 부분식별 범위를 대조하도록 고쳤다. 그러나 같은 부모 조합과
공동 지지를 가진 두 계보가 부모의 순서·재진입·공유 후속의 생성 시점만 달리해 동일한
결합 관측을 만들 수 있다. 공동 분모와 결합 효과를 식별해도 어느 부모의 상태가 먼저
후속을 만들었는지, 여러 부모가 하나의 후속에 실제로 기여했는지, 또는 관측되지 않은
중간 전이가 귀속을 바꾸는지는 결정되지 않는다. 따라서 공동 지지와 의존 운반을 닫는 것만으로
다중 부모의 시간적 귀속과 연속성을 확정할 위험이 남는다.

## 해소 조건

C-003은 공동 지지를 만족하는 부모 조합마다 순서·재진입·공유 후속의 원자화와 시간창을
결과 독립 입력으로 사전 등록하고, 독립 양성·음성·모호 대조와 자연 계보에서 동일한 공동
관측을 만드는 순서·중간 전이 대안을 교차해야 한다. 대안별 시간적 귀속 가능 집합·공동
잠재 분모·조건부·결합 estimand·발견 하한·부분식별 범위를 산출하고, 순서 또는 중간
전이를 식별하지 못하거나 범위가 결론을 바꾸면 해당 다중 부모 귀속·계보·연속성을
보류해야 한다.
