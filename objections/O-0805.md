# O-0805 · 원장 밖 공통 장애가 독립 시계와 배포 자료를 함께 오염시킬 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2613
- 해소: 반복 2621에서 C-003의 주장·근거·한계에 독립 시계·배포 자료·자연 계보가 공유하는 물리 환경·권한·네트워크·복구 경계와 원장 밖 공통 장애 후보를 결과 독립 입력으로 고정하고, 공유하지 않는 환경·권한 경로와 장애 주입·양성·음성 대조에서 전환 경계·누락·미귀속 후보를 교차 검증하도록 실제 반영했다. 원장 밖 공통 원인의 잠재 분모와 최악·최선 범위를 식별하지 못하거나 결론을 바꾸면 해당 구간의 운반·귀속·계보·연속성을 보류하도록 했다.

## 반론

C-003은 버전 원장·기준 시계·배포·복구 기록의 공유 경계를 결과 독립 입력으로 고정하고,
원장을 공유하지 않는 독립 시계·배포 자료와 자연 계보에서 전환 계보와 미귀속 후보를
교차 검증하도록 고쳤다. 그러나 원장을 공유하지 않는 자료도 같은 물리 환경, 권한 중단,
네트워크 분할, 동시 장애 또는 운영자의 공통 복구 판단을 공유할 수 있다. 이 원장 밖
공통 원인이 시계 기록·배포 관측·자연 계보를 동시에 누락시키면, 서로 다른 원장을
사용한 일치가 독립적인 전환 경계 검증이 아니라 같은 장애의 반복일 수 있다.

따라서 원장 공유 경계와 비공유 자료의 교차만으로는 원장 밖 공통 장애의 잠재 분모와
전환 경계 누락의 범위를 식별할 수 없으며, 그 잔여를 분리하지 않으면 해당 구간의 운반·
귀속·계보·연속성을 확정할 수 없다.

## 해소 조건

C-003은 독립 시계·배포 자료·자연 계보가 공유하는 물리 환경·권한·네트워크·복구
경계와 원장 밖 공통 장애 후보를 결과 독립 입력으로 고정해야 한다. 공통 장애를
공유하지 않는 별도 환경·권한 경로와 장애 주입·양성·음성 대조에서 전환 경계·누락·
미귀속 후보를 교차 검증하고, 원장 밖 공통 원인의 잠재 분모와 최악·최선 범위를
식별하지 못하거나 결론을 바꾸면 해당 구간의 운반·귀속·계보·연속성을 보류해야 한다.
