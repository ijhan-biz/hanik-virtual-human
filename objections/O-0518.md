# O-0518 · 고정 식별자 대응이 의미 보존과 반복 전파를 구별하지 못한다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1504
- 해소: 반복 1506에서 C-003의 주장·근거·한계에 식별자의 발급·재사용·폐기·수명과 상태
  지문의 의미 버전·변경 불변식을 결과 독립 입력으로 봉인하고, 동일 식별자의 반복 전파와
  의미 변경·재발급을 별도 계보로 분리했다. 독립 자료와 양성·음성 대조에서 정당한 반복은
  중복 제거하고 변경·재발급은 다중 계수하는지 검증하며, 식별자 수명·의미 보존·분모·누락·
  최악·최선 영향과 계보를 제3자가 재현하지 못하거나 범위가 결론을 바꾸면 해당 시간창과
  교차 계보 판정을 보류하도록 실제 반영했다.

## 반론

C-003은 관측 단위와 경계 상태 전이를 잇는 식별자 대응을 결과와 독립된 입력으로
고정하고, 원자적 분할·병합·중복 제거 규칙으로 교차 전파의 시작·중간·종료를 계보별로
나누도록 고쳤다. 그러나 같은 식별자가 재사용되거나 상태 지문이 불변인 채 의미만
갱신되는 경우, 고정된 대응은 동일한 계보의 반복 전파와 새로운 전파를 구분하지 못할 수
있다.

중복 제거가 내용 지문과 부모 계보만 사용하면 정당한 반복 갱신을 하나의 사건으로 합쳐
전파 횟수와 지연을 줄이고, 반대로 재발급·정규화가 지문을 바꾸면 하나의 전파를 여러
사건으로 셀 수 있다. 독립 자료와 대조가 원자성·누락 범위를 재현해도, 식별자 재사용과
의미 변경의 가능한 범위가 잠재 분모·검출 하한·순서 효과를 바꾸면 교차 계보의 연속성을
확정할 수 없다.

## 해소 조건

C-003은 식별자의 발급·재사용·폐기와 상태 지문의 의미 버전·변경 불변식을 결과와 독립된
입력으로 등록하고, 동일 식별자의 반복 전파·의미 변경·재발급을 별도 계보로 분리해야
한다. 독립 자료와 양성·음성 대조에서 중복 제거가 정당한 반복과 다중 계수를 각각
검출하는지 검증하고, 제3자가 식별자 수명·의미 보존·분모·누락·최악·최선 영향을 재현하지
못하거나 범위가 결론을 바꾸면 해당 시간창과 교차 계보 판정을 보류해야 한다.
