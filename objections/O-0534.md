# O-0534 · 운영 계보 대조의 셀 분모가 사후 선택될 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1553
- 해소: 반복 1556에서 C-003의 주장·근거·한계에 운영 계보 대조의 원자적 모집 단위·셀 귀속·중복·분할·병합 규칙을 결과와 독립된 입력으로 사전 등록하고, 계보 간 결합·교차 전환·재분류 후보를 별도 셀로 열거하도록 실제 반영했다. 각 셀의 분모·누락·최악·최선 영향을 독립 대조와 제3자 재현으로 검증하며, 분모 경계나 교차 셀이 재현되지 않거나 범위가 결론을 바꾸면 해당 시간창과 토큰 의존 판정을 보류하도록 명시했다.

## 반론

C-003은 시계·키·검증자 기록을 운영하는 운영자·동기화·배포·복구·승인 계보와
공유 권한을 독립 입력으로 등록하고, 등록 밖 공통 운영 원인과 개입 후보를 별도
계보로 열거하도록 고쳤다. 그러나 운영 계보가 서로 결합해 하나의 장애를 만들거나,
한 운영 단위가 시간창 중 여러 셀로 분할·재분류되면, 어떤 단위를 한 셀의 분모로
셀지와 셀 사이의 중복을 결과와 독립적으로 정하기 어렵다. 독립 대조가 동일한 셀
경계와 분모를 사용하면 이 사후 집계 선택을 그대로 반복할 뿐이며, 공통 원인을
자극한 결과가 결론을 바꾸는 미분류 교차 셀은 최악·최선 범위에서 빠질 수 있다.
따라서 운영 계보를 등록하고 자극했다는 사실만으로는 셀별 분모와 토큰 의존 판정을
확정할 수 없다.

## 해소 조건

C-003은 운영 계보의 원자적 모집 단위·셀 귀속·중복·분할·병합 규칙을 결과와 독립된
입력으로 사전 등록하고, 계보 간 결합·교차 전환·재분류 후보를 별도 셀로 열거해야
한다. 각 셀의 분모·누락·최악·최선 영향을 독립 대조와 제3자 재현으로 검증하고,
분모 경계나 교차 셀이 재현되지 않거나 범위가 결론을 바꾸면 해당 시간창과 토큰
의존 판정을 보류해야 한다.
