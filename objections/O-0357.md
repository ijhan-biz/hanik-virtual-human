# O-0357 · 외부 분모가 미지의 전이를 실제로 독립 검출하는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 1304
- 해소: 반복 1305에서 C-003의 주장·근거·한계에 외부 분모와 음성 기준이 운영 자료·탐색면과 공유하는 센서·공급자·권한·선택·자원 경계를 결과 전에 분리 등록하고, 공유 경계를 끊은 독립 기준과 자연 사건·무해한 경계 자극으로 외부 분모의 적용 범위와 관측 불능 상태를 교차 검증하도록 명시했다. 경로 공간의 완전성·등록 밖 전이의 탐색률·분모·누락·영향 상한을 유한하게 재현하지 못하면 해당 범위의 운반성·귀속·목록 완전성 및 그 의존 판정을 보류하도록 주장·근거·한계에 반영했다.

## 반론

C-003은 독립 탐색면과 경계 자극으로 적응적 재시도·정책·공급자·공유 자원 전환을
만들고, 외부 분모와 음성 기준을 결과 전에 등록해 등록 밖 전이의 탐색률과 경로 공간의
완전성을 검증하라고 한다. 그러나 외부 분모를 구성하는 기준 자료도 같은 입력 선택,
공급자 정책, 권한 경계, 자원 포화 또는 실패 감지기를 공유하면 관측되지 않은 전이를
독립적으로 세지 못한다. 경계 자극이 만든 전이는 자연 운영에서 발생하는 적응 전이와
다를 수 있고, 음성 기준이 신호 억제나 기록 단절을 포착하지 못하면 낮은 누락률은
검출 가능한 전이에만 조건부인 수치가 된다. 따라서 외부 분모의 독립성·적용 범위와
관측 불능 상태를 어떻게 검증하고, 그 분모가 경로 공간 전체를 덮는다는 근거가 없을 때
탐색률·완전성·영향 상한을 어디까지 보류할지 더 구체화해야 한다.

## 해소 조건

C-003은 외부 분모와 음성 기준이 운영 자료·탐색면과 공유하는 센서·공급자·권한·선택·
자원 경계를 결과 전에 분리 등록하고, 공유 경계를 끊은 독립 기준과 자연 사건·무해한
경계 자극의 교차 검증으로 외부 분모의 적용 범위와 관측 불능 상태를 검사해야 한다.
이 검증으로 경로 공간의 완전성, 등록 밖 전이의 탐색률, 분모·누락·영향 상한을 유한하게
재현하지 못하면 해당 범위의 운반성·귀속·목록 완전성 및 그 의존 판정을 보류한다고
주장·근거·한계에 밝혀야 한다.
