# O-0795 · 공통 의존 그래프의 완전성도 같은 맹점에 의존할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2565
- 해소: 반복 2572에서 C-003의 주장·근거·한계에 공통 의존 그래프의 노드·간선 언어와 독립성 판정 기준을 만드는 감사면의 생성 원천을 결과 독립 입력으로 고정하고, 그래프 밖 공유 원인·판정 불능 후보의 잠재 분모·발견 하한·선택확률·운반 불능 잔여를 대안 언어와 자연 계보에서 최악·최선 범위로 산출하도록 실제 반영했다. 그래프나 감사면의 완전성을 식별하지 못하거나 범위가 결론을 바꾸면 독립성·상태 공간의 교환가능성과 운반·귀속·계보·연속성을 보류하도록 했다.

## 반론

C-003은 온톨로지·적대적 탐색·자연 계보의 생성·관측·검색 자원·목록 생성기 사이 공통 의존
경로와 독립성 판정 규칙을 결과 독립 입력으로 고정하고, 공통 맹점 및 독립성 위반 후보의
범위를 별도로 산출하도록 고쳤다. 그러나 공통 의존 그래프의 노드·간선 언어, 독립성 위반의
판정 기준, 후보를 생성하는 감사면 자체가 같은 온톨로지나 목록 생성기의 사각지대를 물려받으면
그래프에 없는 공유 원인은 식별 대상이 되지 않는다. 세 원천에서 같은 그래프와 같은 최악·최선
범위가 재현되어도 그 일치는 공통 맹점의 결과일 수 있으며, 결과 독립으로 봉인했다는 사실만으로
그래프의 완전성이 보장되지는 않는다.

따라서 공통 의존 경로를 열거했다는 사실만으로는 독립성 위반과 공통 맹점의 잠재 분모를
완전히 제한했다고 할 수 없다.

## 해소 조건

C-003은 공통 의존 그래프의 노드·간선 언어와 독립성 판정 기준을 만드는 감사면의 생성 원천을
별도 결과 독립 입력으로 고정하고, 그래프 밖 공유 원인·판정 불능 후보의 잠재 분모·발견 하한·
선택확률·운반 불능 잔여를 독립적인 대안 언어와 자연 계보에서 최악·최선 범위로 산출해야 한다.
그래프 또는 감사면의 완전성을 식별하지 못하거나 범위가 결론을 바꾸면 독립성·상태 공간의
교환가능성과 운반·귀속·계보·연속성을 보류해야 한다.
