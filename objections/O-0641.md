# O-0641 · 모델별 오류 대조도 후보 중복을 독립적으로 닫지 못할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1907
- 해소: 반복 1931에서 C-003의 주장·근거·한계에 모델·시계 조합 후보의 내용·원인·시간창·원자료 대응과 중복·교차 귀속 규칙을 결과 독립 입력으로 봉인하고, 모델 간 재분류·공동 후보·모델 선택 뒤 탈락 후보를 독립 자료의 양성·음성·모호 대조와 자연 운영에서 생성하도록 실제 반영했다. 중복 제거 전후의 모델·시계 조합별 잠재 분모·발견 하한·최악·최선 영향·미식별 잔여를 산출하며, 제3자 재현 실패나 중복·공유 누락 잔여의 결론 변화 시 해당 조합과 의존하는 연속성을 보류한다.

## 반론

C-003은 보정 모델별 고유·공통·분류 불능 오류와 분모 밖 후보를 별도로 생성하고 모델·
시계 조합별 잠재 분모와 영향 범위를 산출하도록 고쳤다. 그러나 같은 원자료 후보가 여러
모델의 고유 오류와 분류 불능, 또는 여러 시계의 분모 밖 후보로 중복 등장할 수 있다.
후보의 내용·원인·시간창 계보를 모델 사이에서 결과 독립적으로 대응하지 않으면 각 모델의
최악·최선 범위를 합칠 때 한 후보를 여러 번 세거나 공통 후보를 고유 후보로 세게 된다.
반대로 모델 선택 뒤 탈락한 후보를 모델별 분모에 넣지 않으면 공유된 누락이 사라진다.
따라서 C-003은 모델·시계 간 후보의 중복·교차 귀속과 범위 결합이 결론을 바꾸지 않는지
아직 닫지 못한다.

## 해소 조건

C-003은 모델·시계 간 후보의 내용·원인·시간창 계보와 중복·교차 귀속 규칙을 결과 독립
입력으로 등록해야 한다. 동일 후보의 모델 간 재분류, 공동 후보, 모델 선택 뒤 탈락 후보를
독립 자료의 양성·음성·모호 대조 및 자연 운영에서 생성하고, 중복 제거 전후의 잠재 분모·
발견 하한·최악·최선 영향·미식별 잔여를 산출해야 한다. 제3자가 교차 계보와 범위 결합을
재현하지 못하거나 중복·공유 누락 잔여가 결론을 바꾸면 해당 모델·시계 조합과 의존하는
연속성을 보류해야 한다.
