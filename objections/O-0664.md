# O-0664 · 선택 확률의 지지 공백이 모델 운반의 반사실을 식별하지 못할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2011
- 해소: 반복 2014에서 C-003의 주장·근거·한계에 선택 전 신호·운영 상태별 각 모델과 대체 경로의 양의 지지·공통 지지 중첩 조건, 결과 독립 진단과 지지 밖 후보의 잠재 분모를 사전 고정하도록 실제 반영했다. 자연 운영 및 독립 양성·음성·모호 대조에서 지지 셀·공통 지지 셀·지지 밖 셀과 선택·대체 순서를 교환하고, 셀별 선택 확률·미선택·대체·운반 불능 분모·발견 하한·최악·최선 영향·미식별 잔여를 분리 산출한다. 제3자 재현 실패 또는 지지 밖 잔여의 결론 변화 시 해당 복원 층의 결론과 의존 연속성을 보류한다.

## 반론

C-003은 선택 전 신호와 선택되지 않은 후보를 결과 독립 입력으로 고정하고, 선택 확률과
모델·층별 분모를 자연 운영 및 독립 대조에서 교환하도록 고쳤다. 그러나 어떤 선택 전
신호·운영 상태에서는 특정 모델이 구조적으로 선택되지 않거나 실패 후에만 대체된다면,
그 층에는 선택 확률의 지지 공백이 생긴다. 순서를 교환해도 관측된 후보의 선택 확률을
선택되지 않은 후보의 잠재 결과로 운반할 수 없고, 미선택 분모를 최악·최선 범위로 넓히는
것만으로는 선택 편향과 운반 실패의 방향을 식별하지 못한다. 따라서 모델 선택 확률의
양의 지지·중첩 기준과 지지 밖 후보의 결론 영향이 아직 닫히지 않았다.

## 해소 조건

C-003은 선택 전 신호·운영 상태별로 각 모델과 대체 경로가 선택될 양의 지지·중첩 조건,
그 조건을 확인하는 결과 독립 진단과 지지 밖 후보의 잠재 분모를 사전 고정해야 한다.
자연 운영 및 독립 양성·음성·모호 대조에서 지지 셀·공통 지지 셀·지지 밖 셀을 교환하고,
셀별 선택 확률·미선택·대체·운반 불능 분모와 발견 하한·최악·최선 영향·미식별 잔여를
분리 산출해야 한다. 제3자가 지지 진단·선택 계보·산출을 재현하지 못하거나 지지 밖
잔여가 결론을 바꾸면 해당 복원 층의 결론과 의존 연속성을 보류해야 한다.
