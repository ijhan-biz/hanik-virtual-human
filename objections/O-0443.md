# O-0443 · 원자적 계보가 외부 효과의 실제 봉인을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1427
- 해소: 반복 1428에서 C-003의 주장·근거·한계에 내부 원자적 전환을 외부 공급자·권한 중재기·큐·캐시의 효과 수신·적용·확인·멱등성·보상 경계와 결과 전에 함께 봉인하도록 실제 반영했다. 외부 효과의 수신·적용·중복·재시도·되돌림과 내부 계보 연결을 독립 교란에서 검증하고, 불일치의 잠재 기회 분모·생성률·최대 영향·부모-자식 회수 계보를 내부 커밋 수치와 별도 산출하도록 했으며, 제3자가 같은 입력으로 외부 효과의 커밋·확인·보류와 유한한 종료를 재현하지 못하면 전환 잔여와 그에 의존하는 귀속·연속성을 확정하지 않도록 명시했다.

## 반론

C-003은 효과 적용과 전환 계보 보존을 하나의 원자적 커밋 경계로 묶고, 동시 전환의
선형화와 지연·중복·단절·부분 적용·롤백·재진입의 보류를 재현하지 못하면 전환을
확정하지 않도록 고쳤다. 그러나 그 원자 경계가 내부 기록면의 커밋만 묶는다면 공급자,
권한 중재기, 큐, 캐시처럼 외부에 이미 노출된 효과의 실제 적용과 내부 계보 커밋 사이에
비가역적인 구간이 남는다. 외부 시스템이 승인·거부·예약·회수나 재시도를 내부 커밋과
다르게 처리하거나, 확인 응답을 잃은 뒤 같은 효과를 다시 수행하면 내부 원자성은 두
개의 외부 결과를 하나의 전환으로 만들거나 효과 없는 전환을 유효한 계보로 만들 수 있다.

독립 교란으로 내부 커밋의 순서와 보류를 재현해도 외부 효과의 수신·적용·중복 억제·
되돌림 경계와 확인 응답의 의미를 별도로 닫지 않으면 효과-계보 불일치의 잠재 기회
분모·생성률·최대 영향·부모-자식 회수 범위를 산출할 수 없다. 따라서 외부 효과의
관찰 가능한 커밋·멱등 키·확인·보상 경계와 내부 전환 계보의 연결을 같은 입력으로
유한하게 재현하고 보류하지 않으면 C-003은 실제 효과에 대한 변경 전후 귀속과
연속성을 확정할 수 없다.

## 해소 조건

C-003은 내부 원자적 전환과 외부 공급자·권한·큐·캐시의 효과 적용·확인·멱등성·보상
경계를 결과 전에 함께 봉인해야 한다. 외부 효과의 수신·적용·중복·재시도·되돌림과
내부 계보 연결을 독립 교란으로 검증하고, 불일치의 잠재 기회 분모·생성률·최대 영향·
부모-자식 회수 계보를 내부 커밋 수치와 별도 산출해야 한다. 제3자가 같은 입력으로
외부 효과의 커밋·확인·보류와 유한한 종료를 재현하지 못하면 해당 전환 잔여와 그에
의존하는 귀속·연속성을 확정하지 않아야 한다.
