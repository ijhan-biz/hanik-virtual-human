# O-0590 · 교차 훈련 대조가 개념의 실제 사용을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1720
- 해소: 반복 1722에서 C-003의 주장·근거·한계에 자연 운영의 라벨러 적용 조건과 모호 사례의 합의·보류 규칙, 권한·피로·피드백을 결과와 독립된 입력으로 등록하고, 훈련 밖 양성·음성·모호 자극을 계보·라벨러·교정 절차별로 교차해 실제 적용의 불일치·합의·보류·미관측을 검출하도록 실제 반영했다. 유형별 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 공통 오류와 분리해 산출하며, 제3자 재현 실패나 잔여의 결론 변화 시 해당 계보의 운반 자격과 의존 연속성을 보류한다.

## 반론

C-003은 판정 개념·라벨러 훈련·교정 기준의 공유 경계를 결과와 독립된 입력으로
등록하고, 개념을 교란한 자극과 절차를 교차해 공통 오류와 계보별 불일치를 검출하도록
고쳤다. 그러나 훈련 자료와 교정 절차를 교차했다는 사실만으로 라벨러가 실제 자연
운영에서 그 개념을 같은 방식으로 적용한다고 보장할 수 없다. 라벨러가 모호한 사례를
사후 합의로 처리하거나, 계보별 권한·피로·피드백이 판정 기준의 사용을 바꾸면 등록된
공유 경계와 대조의 오류율은 실제 판정의 잠재 분모를 대표하지 못한다. 따라서 개념의
실제 적용과 모호 사례의 미관측을 분리하지 않으면 계보별 불일치와 공통 판정 오류의
결론 영향이 아직 닫히지 않는다.

## 해소 조건

C-003은 자연 운영에서 라벨러가 판정 개념을 적용하는 조건, 모호 사례의 합의·보류
규칙, 권한·피로·피드백에 따른 기준 사용 변화를 결과와 독립된 입력으로 등록해야 한다.
훈련 밖의 양성·음성 및 모호 자극을 계보·라벨러·교정 절차별로 교차하고, 실제 적용
불일치·합의·보류·미관측을 검출해야 한다. 유형별 잠재 분모·식별 가능성 하한·최악·최선
영향·보류 전파를 공통 오류와 분리해 산출하고, 제3자 재현 실패나 잔여가 결론을 바꾸면
해당 계보의 운반 자격과 의존 연속성을 보류해야 한다.
