# O-0751 · 독립 대조의 비공유성이 경로 포괄성을 식별한다는 보장이 없다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2364
- 해소: 반복 2368에서 C-003에 경로별 기준 진실·접근 지지집합·교란 강도·재표집 단위를 결과와 독립된 입력으로 등록하고, 공통 사각지대와 경로 조합 개입의 지지집합 변화를 별도 산출하도록 반영함. 경로·조합별 공유 누락·의존·공동 잠재 분모·발견 하한·부분식별 범위와 최악·최선을 검증하고, 비공유성·포괄성을 식별하지 못하거나 범위가 결론을 바꾸면 해당 층의 외삽·운반·귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 교란·재표집 경로가 원인·측정면·결합 구조를 덮는지 독립 대조로 검증하고,
경로별 포괄성·공유 누락·의존 구조를 결과 독립 입력으로 봉인하도록 고쳤다. 그러나
독립 대조가 서로 다른 실행으로 만들어졌다는 사실은 각 경로가 같은 잠재 대안 공간을
탐색했다는 뜻이 아니다. 대조의 기준 진실, 접근 가능한 단위, 교란 강도 또는 재표집
지지집합이 공통으로 제한되면, 경로 간 불일치와 공유 누락을 분리하는 포괄성 검증 자체가
그 사각지대를 전제한다. 경로 조합별 공동 잠재 분모와 발견 하한을 계산해도 조합 개입이
새 원인·측정면을 제거하거나 생성해 관측 지지를 바꾸는 경우가 있어, 결과 독립 등록만으로
자연 계보에 운반할 수 있는 경로임을 식별할 수 없다.

## 해소 조건

C-003은 경로별 포괄성 대조의 기준 진실·접근 지지집합·교란 강도·재표집 단위를 서로
독립적인 결과 독립 입력으로 등록하고, 공통 사각지대와 경로 조합 개입이 만드는 지지집합
변화를 별도 산출해야 한다. 각 경로·조합의 공유 누락·의존·공동 잠재 분모·발견 하한·
부분식별 범위와 최악·최선을 검증해 운반 가능성을 판정하고, 대조의 비공유성 또는 경로
포괄성을 식별하지 못하거나 범위가 결론을 바꾸면 해당 층의 귀속·계보·연속성을 보류해야 한다.
