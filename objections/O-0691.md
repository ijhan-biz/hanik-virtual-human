# O-0691 · 종료 표지가 지연 검출의 시간 경계를 다시 전제할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2103
- 해소: 반복 2116에서 C-003의 주장·근거·한계에 종료 표지·시계·기록면·재진입의 계보와 중복·지연·소실 규칙을 결과 전에 독립 봉인하고, 종료 경계를 흔든 대조와 후보 생성·검출 시점의 순서를 바꾼 대조를 등록하도록 실제 반영했다. 경계 오분류율, 미관측·재진입 후보의 잠재 분모, 단계별 생성률·누락률과 지연 잔여의 최악·최선 영향을 따로 산출하며, 종료 경계를 재현하지 못하거나 시간 귀속 잔여가 결론을 바꾸면 생성 계보·시간 귀속·연속성을 보류한다.

## 반론

C-003은 초기화·적응·종료 자극과 자료를 독립 입력으로 고정하고, 종료 후 지연 검출
후보를 종료 전 생성·종료 시점 미관측·종료 후 생성 또는 검출로 나누어 별도 봉인하도록
고쳤다. 그러나 이 분류는 종료 시점이 관측 가능한 하나의 경계이고, 후보의 생성과 검출
시점이 서로 구별된다는 전제에 의존한다. 시계·기록면·자원 갱신이 적응 경로와 공유되거나
종료 신호가 지연·중복·재진입될 때에는 종료 전에 생성된 후보가 종료 후 생성된 것처럼
보이거나, 종료 뒤에야 드러난 후보가 실제로는 종료 전에 소실된 후보인지 판별할 수 없다.
단계별 생성률과 잠재 분모를 교차 산출해도 이 시간 경계의 오분류가 공통으로 남으면
지연 잔여의 최악·최선 범위와 귀속 보류가 같은 봉인된 종료 표지를 다시 전제한다.

## 해소 조건

C-003은 종료 표지·시계·기록면·재진입의 계보와 중복·지연·소실 규칙을 결과 전에 독립
봉인하고, 종료 경계의 교란 및 후보 생성-검출 시점의 순서를 바꾼 대조에서 경계 오분류율,
미관측·재진입 후보의 잠재 분모, 단계별 생성·누락률과 최악·최선 영향을 따로 산출해야
한다. 종료 경계를 재현하지 못하거나 시간 귀속의 잔여가 결론을 바꾸면 해당 지연 후보의
생성 계보·귀속·연속성을 보류해야 한다.
