# O-0199 · 외부 기준과 포착 시험도 같은 경계를 공유하지 않는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0706
- 해소: 반복 0712에서 C-003에 외부 기준 집단과 포착 시험이 공유하는 상태 공간·표집 경계·주입 가능성의 한계를 드러내는 독립 경계 교란과 포착률 상한 검사를 도입했다. 표집틀 밖 상태·극단·상호작용을 독립 운영 기록과 대조하고 경계 안·밖을 바꾸는 교란을 주입하며, 주입 불능·정의 이전 신호까지 분모에 고정한 최악 포착률을 상한으로 산출하도록 했다. 두 검사의 계보가 기준 집단·시험과 겹치거나 미지 상태·극단·상호작용을 가르지 못하면 누락률을 경계 밖에 일반화하지 않고 공동 미관측 셀의 후보·영향 범위·의존 산출물을 보류하며, 직접 검증된 상태·시간창·변수와 상한이 덮는 범위에서만 해제하도록 주장·근거·한계에 반영했다.

## 반론

C-003은 외부 기준 집단과 포착 시험으로 별도 탐색과 독립 대조가 함께 놓칠 수
있는 상태를 찾고, 두 검사가 직접 덮은 교집합에서만 결과를 해제하도록 고쳤다.
그러나 외부 기준 집단의 경계 사례를 뽑는 절차와 포착 시험에 주입할 실패·정의
이전 신호는 이미 알려진 상태 분류와 운영 환경에 의존한다. 실제로는 시험에
주입할 수 없는 경로, 기준 집단에 표집되지 않는 극단, 두 검사 모두에서 재현할 수
없는 상호작용이 있을 수 있으며, 포착률·누락률의 추정도 그 미지의 상태를
분모에서 제외한 값일 수 있다. 두 검사가 서로 다른 출처를 사용해도 같은 상태
공간의 경계를 공유한다면, 교집합에서 결과 불변성이 확인된다는 사실은 경계 밖
공동 미관측 셀이 후보 방향과 영향 범위를 바꾸지 않는다는 보장이 아니다.

## 해소 조건

C-003은 외부 기준 집단과 포착 시험이 공유하는 상태 공간·표집 경계·주입 가능성의
한계를 드러내는 독립적인 경계 교란 또는 포착률 상한 검사를 제시해야 한다. 그
검사가 기준 집단과 시험의 미지 상태·극단·상호작용을 가르지 못하면, 추정한
누락률을 경계 밖에 일반화하지 말고 해당 공동 미관측 셀의 후보·영향 범위·의존
산출물을 보류하는 기준과 직접 검증 범위에서만 해제하는 사용 한계를 밝혀야 한다.
