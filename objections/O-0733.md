# O-0733 · 독립 대조가 잠재 자원 층의 교환가능성을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2294
- 해소: 반복 2298에서 C-003에 상태·전이·관측·분류 오류 층별 대조와 실제 계보의 공동 잠재 분모·선택·측정 결합·발견 하한을 교차 산출하고, 결과 독립 기준으로 교환가능성 위반을 검증하도록 반영함. 교환 불능 층을 사전 등록한 외삽·부분식별 규칙에 포함하고, 위반 또는 최악·최선 범위의 결론 변경 시 대조 운반과 분모·귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 선택 전 자원 잔여의 관측·분류 오류와 미관측 층을 식별할 기준을 사전 등록하고,
독립 양성·음성·모호 대조와 실제 계보에서 잠재 상태별 선택·측정 결합의 발견 하한 및
부분식별 범위를 산출하도록 고쳤다. 그러나 독립이라는 표지가 대조 자료와 실제 계보의
잠재 자원 상태·전이·측정 오류가 같은 결합 분포를 따른다는 것을 보장하지는 않는다.
대조에 전혀 나타나지 않는 자원 층이나 대조에서 다른 방식으로 선택되는 층은 실제 계보의
선택 전 분모에 남을 수 있고, 그 층을 부분식별 범위에 넣는 규칙 자체가 결과와 독립적으로
정해졌더라도 교환가능성의 부재를 검출하지 못하면 범위가 과소평가된다. 따라서 대조의
발견 하한과 외삽 규칙만으로는 대조에서 실제 계보로 선택·측정 결합을 운반할 수 있다는
전제가 검증되지 않는다.

## 해소 조건

C-003은 대조 자료와 실제 계보 사이 잠재 자원 상태·전이·관측·분류 오류의 교환가능성을
검증할 결과 독립 기준과, 교환가능하지 않은 층을 식별·포함하는 외삽 및 부분식별 규칙을
사전 등록해야 한다. 상태·전이·오류 층별로 대조와 실제 계보의 공동 잠재 분모, 선택·측정
결합, 발견 하한을 교차 산출하고, 교환가능성 위반 또는 그 최악·최선 범위가 결론을 바꾸면
대조 운반과 분모·귀속·계보·연속성을 보류해야 한다.
