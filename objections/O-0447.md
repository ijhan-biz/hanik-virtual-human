# O-0447 · 고정된 공개 경계도 수신자별 부분 전달을 닫지 못한다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1431
- 해소: 반복 1432에서 C-003의 주장·근거·한계에 수신자별 공개 내용·전달·수신 확인과 권한 유효 시점을 결과 전에 봉인하고, 중개자·캐시·거부·회수·지연의 부분 전달 규칙과 재진입 경계를 별도로 고정하도록 실제 반영했다. 수신자별 공개 전후 잠재 기회 분모·생성률·최대 영향·부모-자식 회수 계보와 관측 불능 잔여를 분리 산출하고, 부분 공개를 아는 독립 교란에서 외부 연쇄와 유한한 종료를 검증하며, 제3자가 같은 입력과 수신자별 공개 경계로 산출과 종료를 재현하지 못하면 공개에 의존하는 귀속·연속성을 확정하지 않도록 명시했다.

## 반론

C-003은 단말 판정·검증 결과의 공개 시점과 수신자, 권한 변화를 고정하고 공개를 아는
독립 교란에서 공개 뒤 외부 연쇄의 재진입과 유한한 종료를 검증하도록 고쳤다. 그러나
중개자나 수신자가 결과를 일부만 받거나 늦게 받거나, 캐시·권한 회수·수신 거부로 공개의
실제 경계를 다르게 경험하면 동일한 공개 시각과 수신자 목록이 실제 행위자의 정보
집합을 고정하지 못한다. 한 수신자에게만 전달된 단말 결과가 새 웹훅·재시도·권한 요청을
만들고 다른 수신자에게는 전달되지 않으면, 공개를 아는 독립 교란의 결과도 어느 부분
공개를 받은 행위자의 선택을 재현한 것인지 결정할 수 없다.

공개 전후 분모·생성률·최대 영향·부모-자식 계보를 분리해도 수신자별 누락·지연·부분
전달의 기회가 분모에서 빠지거나, 동일한 공개 경계 안에서 서로 다른 권한 상태가
섞이면 관측 불능 잔여가 남는다. 따라서 수신 확인·전달 내용·권한 유효 시점과 캐시·
거부·회수의 경계를 별도로 봉인하고 재현하지 않으면 C-003은 공개에 의존하는 외부
귀속·연속성을 확정할 수 없다.

## 해소 조건

C-003은 수신자별 공개 내용·전달·수신 확인과 권한 유효 시점을 결과 전에 봉인하고,
중개자·캐시·거부·회수·지연으로 생기는 부분 전달 규칙과 재진입 경계를 별도로 고정해야
한다. 수신자별 공개 전후 잠재 기회 분모·생성률·최대 영향·부모-자식 회수 계보와 관측
불능 잔여를 분리 산출하고, 부분 공개를 아는 독립 교란에서 외부 연쇄와 유한한 종료를
검증해야 한다. 제3자가 같은 입력과 수신자별 공개 경계로 이 산출과 종료를 재현하지
못하면 공개에 의존하는 귀속·연속성을 확정하지 않아야 한다.
