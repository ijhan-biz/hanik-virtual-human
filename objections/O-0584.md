# O-0584 · 재정렬 규칙이 결측 오분류의 시간적 원인을 가릴 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1685
- 해소: 반복 1693에서 C-003의 주장·근거·한계에 운반 실패와 상태 관측 실패의 선후가 식별되지 않는 경로를 결과와 독립된 입력으로 등록하고, 기록면별 지연 분포·재정렬 창·결측 판정 시계·기록면·재정렬 규칙과 세 유형 사이의 오분류 경계를 사전 고정하도록 실제 반영했다. 독립 자료와 변경 전후·교차 계보의 양성·음성 자극에서 지연 순서를 교환·중첩한 대조를 생성·검출하며, 시간적 오분류별 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 운반 단독 효과와 재학습·기대 변화 결합에 각각 따로 적용한다. 제3자가 시간적 분해와 산출을 재현하지 못하거나 범위가 결론을 바꾸면 해당 대조와 의존 연속성을 보류한다.

## 반론

C-003은 결측 유형의 판정 시계·기록면·재정렬 규칙과 오분류 경계를 결과와 독립된 입력으로
고정하고, 독립 자료와 양성·음성 자극에서 각 유형과 오분류를 검출하도록 고쳤다. 그러나
여러 기록면의 지연과 재정렬이 같은 실행에서 겹치면, 사전 고정된 규칙은 관측 순서를
일관되게 만들 뿐 운반 실패가 먼저였는지 상태 관측 실패가 먼저였는지를 복원하지 못할 수
있다. 특히 재정렬 창 안에 들어온 늦은 상태 기록을 운반 결측의 음성으로 세거나, 반대로
운반 기록의 지연을 상태 결측으로 세면 오분류별 잠재 분모와 결합 효과의 범위가 달라진다.
양성·음성 자극의 재현만으로는 자연 운영의 지연 순서와 기록면 간 시차가 같은지 보이지
않으므로, 현재의 경계 검출은 시간적 원인이 비식별인 경우를 충분히 보류한다고 확정할 수
없다.

## 해소 조건

C-003은 기록면별 지연·재정렬 창과 운반·상태 관측의 선후가 비식별인 경로를 결과와 독립된
입력으로 사전 등록해야 한다. 독립 자료와 변경 전후·교차 계보의 양성·음성 자극에서 지연
순서를 교란한 대조를 생성·검출하고, 시간적 오분류별 잠재 분모·식별 가능성 하한·최악·
최선 영향·보류 전파를 운반 단독 효과와 학습·기대 변화의 결합에 따로 적용해야 한다.
제3자가 시간적 분해와 산출을 재현하지 못하거나 범위가 결론을 바꾸면 해당 대조와 의존
연속성을 보류해야 한다.
