# O-0569 · 조건화 규칙이 지지 영역의 공통성을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1640
- 해소: 반복 1642에서 C-003의 주장·근거·한계에 개입 전 공변량별 개입·비개입의 양의 지지와 중간 상태 관측 가능성, 자연 운영·독립 자료의 지지 겹침 규칙을 결과 독립 입력으로 사전 등록하고, 독립 자료와 양성·음성 대조에서 지지 밖 공변량 층·관측 불능 중간 상태·절단·재가중 후보를 검출하도록 실제 반영했다. 층별 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 산출하며 지지 겹침·보정 범위·운반 계보의 제3자 재현 실패나 지지 밖 범위의 결론 변경 시 해당 셀과 의존 판정을 보류한다.

## 반론

C-003은 개입 전 공변량과 개입 후 중간 상태를 구분하고 조건화 전후의 공동분포와 효과
수정자를 대조하도록 고쳤다. 그러나 조건화 규칙이 개입 전 공변량별 개입의 양의 지지와
자연 운영의 지지 영역을 겹치게 만든다는 보장은 없다. 일부 공변량 층에서 개입이 거의
없거나 중간 상태가 특정 경로에서만 관측되면, 식별 가능성 하한은 관측 가능한 선택된
층에만 성립하고 지지 밖 층의 운반 효과를 대신할 수 없다. 따라서 조건화 규칙과 효과
수정자 범위를 재현해도 지지 겹침의 결손을 별도 분모로 세지 않으면 셀별 보류 범위와
연속성 판정을 확정할 수 없다. 특히 재가중이 희귀 층을 안정적으로 복원한다는 가정은
관측된 중간 상태의 선택 편향을 제거하지 못할 수 있다.

## 해소 조건

C-003은 개입 전 공변량별 개입·비개입의 양의 지지와 중간 상태 관측 가능성, 자연 운영과
독립 자료의 지지 겹침 규칙을 결과와 독립된 입력으로 사전 등록해야 한다. 독립 자료와
양성·음성 대조에서 지지 밖 공변량 층, 관측 불능 중간 상태, 절단·재가중 후보를 검출하고
층별 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 산출해야 한다. 지지 겹침과
보정 범위를 제3자가 재현하지 못하거나 지지 밖 범위가 결론을 바꾸면 해당 셀과 의존하는
운반·연속성 판정을 보류해야 한다.
