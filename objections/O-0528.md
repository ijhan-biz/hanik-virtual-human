# O-0528 · 독립성 경계의 관측자 자체가 공통 원인일 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1538
- 해소: 반복 1541에서 C-003의 주장·근거·한계에 운영자·권한·정책·복구 경계의 식별자 대응·분류 규칙과 독립성 검증자·승인자 계보를 결과 독립 입력으로 등록하고, 위임·긴급 계정·자동화·로그 보정 후보를 별도 계보로 열거했다. 독립 자료와 양성·음성 대조에서 검증자 계보의 공유·변경·폐기를 자극해 관측 불능 후보의 잠재 기회 분모와 최악·최선 영향을 산출하고, 제3자 재현 실패 또는 범위의 결론 변화에서 해당 시간창과 토큰 의존 판정을 보류하도록 실제 반영했다.

## 반론

C-003은 생성자·서명 주체의 운영자 집합, 권한, 정책, 복구 경계를 결과와 독립된
입력으로 분해하고, 독립 자료의 양성·음성 대조에서 공유·변경·대체·폐기를 자극하도록
고쳤다. 그러나 어떤 운영자·권한·정책·복구가 실질적으로 같은지 판정하는 식별자 대응과
경계 분류, 그리고 그 대조의 관측자를 승인하는 권한이 두 자료와 같은 조직 계보나
복구 경로를 공유할 수 있다. 독립성 검증자가 공통 운영자·정책의 누락을 관측하지
못하면, 제3자가 같은 입력과 절차를 재현해도 동일한 관측 불능을 반복할 뿐이다.

또한 등록 밖의 위임·긴급 계정·운영 자동화·사후 로그 보정이 있었던 시간창은 잠재
기회 분모와 최악·최선 영향에 들어가더라도 그 경계의 공통 여부를 판정할 수 없다.
따라서 경계 식별 규칙과 검증자 계보의 공통 원인, 관측 불능 후보를 독립적으로 닫지
못하면 해당 대조와 토큰 의존 판정은 확정할 수 없다.

## 해소 조건

C-003은 운영자·권한·정책·복구 경계의 식별 규칙과 독립성 검증자·승인 계보를 결과와
독립된 입력으로 등록하고, 위임·긴급 계정·자동화·로그 보정 후보를 별도 계보로
열거해야 한다. 독립 자료와 양성·음성 대조에서 검증자 계보의 공유·변경·폐기를
자극해 관측 불능 후보의 잠재 기회 분모와 최악·최선 영향을 산출하고, 제3자 재현
실패 또는 범위의 결론 변화에서 해당 시간창과 토큰 의존 판정을 보류해야 한다.
