# O-0793 · 독립 탐색들이 같은 맹점을 공유할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2563
- 해소: 반복 2565에서 C-003에 세 탐색 원천의 생성·관측·검색 자원·목록 생성기 사이 공통 의존 경로와 독립성 판정 규칙을 결과 독립 입력으로 봉인하고, 공통 맹점·독립성 위반 후보의 잠재 분모·발견 하한·선택확률·운반 불능 잔여를 별도 최악·최선 범위로 독립 대조와 자연 계보에서 교차하도록 주장·근거·한계에 실제 반영했다. 이를 식별하지 못하거나 범위가 결론을 바꾸면 상태 공간의 완전성과 교환가능성, 운반·귀속·계보·연속성을 보류하도록 했다.

## 반론

C-003은 상태 공간의 생성 원천과 등록 밖 상태·전이의 탐색 규칙을 결과 독립으로 고정하고,
독립 온톨로지·적대적 탐색·자연 계보에서 미등록 후보의 잠재 분모와 발견 하한을 교차하도록
고쳤다. 그러나 독립이라고 지정한 온톨로지와 적대적 탐색이 같은 관측 언어·생성 가정·검색
자원에 의존하거나, 자연 계보 자체가 같은 목록 생성기를 거쳐 구성되면 세 원천이 공통으로
누락한 상태·전이를 발견할 수 없다. 이 경우 서로 다른 방법에서 같은 발견 하한과 선택확률이
나와도 진정한 독립성이나 미등록 후보의 분모를 보장하지 못하며, ‘독립’이라는 분류가 결과
후에 붙은 명칭이면 반론을 검출하지 못한다.

따라서 세 탐색 원천의 공통 생성·관측·검색 의존성과 독립성의 검증 가능성을 별도로 식별하지
않고서는 상태 공간의 완전성, 운반 불능 잔여 또는 그에 기초한 연속성을 확정할 수 없다.

## 해소 조건

C-003은 온톨로지·적대적 탐색·자연 계보의 생성·관측·검색 자원·목록 생성기 사이 공통 의존
경로와 독립성 판정 규칙을 결과 독립 입력으로 고정하고, 공통 맹점·독립성 위반 후보의 잠재
분모·발견 하한·선택확률·운반 불능 잔여를 별도 최악·최선 범위로 산출해야 한다. 공통 의존
또는 독립성 위반을 식별하지 못하거나 그 범위가 결론을 바꾸면 상태 공간의 완전성과 교환가능성,
운반·귀속·계보·연속성을 보류해야 한다.
