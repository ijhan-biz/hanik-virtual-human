# O-0741 · 공통 원인 후보의 독립 대조가 결합된 미관측 경로를 닫는다는 보장이 없다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2336
- 해소: 반복 2342에서 C-003에 공통 원인의 단독·쌍·고차 결합과 측정면 선택 변경 경로를 결과 독립 입력으로 등록하고, 결합별 공동 잠재 분모·조건부·주변 estimand·발견 하한·부분식별 범위를 독립 대조에서 산출하도록 반영함. 결합 경로의 생성·종료·중복 제거·귀속을 재현하지 못하거나 등록 밖 고차 원인의 최악·최선 범위가 결론을 바꾸면 해당 층의 외삽·운반·귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 측정면 사이의 교정·장비·운영자·시간창·미관측 층 공유 후보와 등록 밖 공통
원인을 열거하고, 독립 대조에서 비공유성과 후보별 공동 잠재 분모를 검증하도록 고쳤다.
그러나 각 측정면의 비공유성을 후보별로 확인해도 여러 공통 원인이 결합하거나 한 원인이
측정면 선택 자체를 바꾸는 경로는 단일 후보 대조에서 분리되지 않을 수 있다. 등록 밖
탐색의 발견 하한도 대조가 관측하는 결합만을 기준으로 하면, 모든 면에서 함께 사라지는
고차 공통 원인과 그로 인한 잠재 분모를 하한 밖에 남긴다. 따라서 후보별 범위와 비공유성
검증을 합쳤다는 것만으로 공통 원인들의 결합 경로가 전체 계보의 귀속과 연속성을 식별한다는
결론은 보장되지 않는다.

## 해소 조건

C-003은 공통 원인 후보의 단독·쌍·고차 결합과 측정면 선택을 바꾸는 경로를 결과 독립
입력으로 사전 등록하고, 결합별 공동 잠재 분모·조건부·주변 estimand·발견 하한·부분식별
범위를 독립 대조에서 산출해야 한다. 결합 경로를 생성·종료·중복 제거·귀속까지 재현하지
못하거나 등록 밖 고차 원인의 최악·최선 범위가 결론을 바꾸면 해당 층의 외삽·운반·귀속·
계보·연속성을 보류해야 한다.
