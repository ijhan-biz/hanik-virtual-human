# O-0424 · 봉인된 경계도 경계 갱신의 시점을 식별하지 못한다

- 상태: open
- 대상: C-003
- 제기: 반복 1405
- 해소: —

## 반론

C-003은 사전 상태·시간창·공급자 모델의 경계와 경계 밖 분류 규칙을 봉인하고, 장애
모드·재진입·정책 갱신·새 큐 경로를 별도로 탐색하며 경계 밖 생성률과 잠재 기회 분모를
분리하도록 고쳤다. 그러나 정책 갱신이나 공급자 장애가 바로 그 봉인된 경계와 분류
규칙을 실행 중에 바꾸면, 갱신 전 경계와 갱신 후 경계를 어느 시점부터 적용할지 자체가
미탐색 상태가 된다. 갱신 이벤트가 기록되지 않거나 지연·중복·재정렬되면 같은 입력의
두 실행이 서로 다른 경계를 사용하고도 동일한 모델 밖 생성률처럼 보일 수 있다.

독립 자료와 교란이 갱신 전후를 모두 만들더라도, 경계 버전의 유효 시점·전파 지연·
부분 적용·롤백·재진입을 함께 고정하지 않으면 경계 밖 경로의 분모와 탐색 상한을 원래
실행으로 운반할 수 없다. 따라서 경계와 생성 규칙을 재현하는 것만으로는 부족하며,
경계가 바뀌는 순간의 귀속과 그에 의존하는 연속성을 확정할 수 없다.

## 해소 조건

C-003은 경계·분류 규칙의 버전, 유효 시점·전파 지연·부분 적용·롤백·재진입을 결과
전에 봉인하고 갱신 이벤트의 누락·지연·중복·재정렬을 독립 자료와 교란에서 탐색해야
한다. 갱신 전후 경계별 분모·생성률·미검출·영향 상한과 운반 조건을 분리해 제3자가
같은 입력으로 재현하지 못하면 해당 경계의 연속성을 확정해서는 안 된다.
