# O-0745 · 사전 등록한 귀속 대안의 완전성이 독립 대조로 보장되지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2345
- 해소: 반복 2349에서 C-003에 귀속 대안 공간의 완전성 기준과 등록 밖 고차 원인·측정면 선택 경로를 찾는 결과 독립 탐색 규칙을 고정하고, 독립 양성·음성·모호 대조와 등록 밖 탐색에서 미포괄 대안의 발견 하한·공동 잠재 분모·조건부·주변 estimand·부분식별 범위를 산출하도록 반영함. 완전성을 식별하지 못하거나 미포괄 대안의 최악·최선 범위가 결론을 바꾸면 해당 원인층의 운반·귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 관측적으로 같은 결합 분포를 만드는 고차 원인 귀속의 대안과 측정면 선택
경로를 사전 등록하고, 귀속별 공동 잠재 분모와 부분식별 범위를 독립 대조에서
산출하도록 고쳤다. 그러나 사전 등록된 대안 목록이 관측면 밖에서 같은 분포를 만드는
모든 원인층을 포괄한다는 보장은 없다. 독립 대조의 발견 하한도 등록된 귀속 언어와
측정면이 공유하는 맹점에 걸리면, 등록되지 않은 원인이 기존 대안의 최악·최선 범위에
들어가지 않은 채 계보에 운반될 수 있다. 따라서 귀속별 범위를 산출하고 귀속 불능을
보류하는 것만으로는 대안 공간 누락으로 인한 고차 원인의 귀속과 연속성을 식별할 수 없다.

## 해소 조건

C-003은 사전 등록한 귀속 대안 공간의 완전성 기준과 등록 밖 고차 원인·측정면 선택
경로를 발견하는 결과 독립 탐색 규칙을 함께 고정해야 한다. 독립 양성·음성·모호
대조와 등록 밖 탐색에서 미포괄 대안의 발견 하한·공동 잠재 분모·조건부·주변
estimand·부분식별 범위를 산출하고, 대안 공간이 완전하다고 식별하지 못하거나
미포괄 대안의 최악·최선 범위가 결론을 바꾸면 해당 원인층의 운반·귀속·계보·연속성을
보류해야 한다.
