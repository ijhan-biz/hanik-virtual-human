# O-0211 · 동일한 산출물이 여러 사용 사건을 합치지 않는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0741
- 해소: 반복 0756에서 C-003에 동일·근접 산출물의 반복 사용과 하나의 판정에 합쳐진 다중 사용을 사건별 원자료·변환·수신·판정 표지와 시간창으로 분리하고, 생성·전달·판정의 순서·시간 상한·표지 중복·누락을 결과 전에 검사하도록 반영했다. 같은 지문·변환이나 공통 사후 증거로 사건 귀속을 가를 수 없으면 가능한 사건 묶음과 그 자산·사용·의존 판정을 보류하고, 새 원자료가 특정 사건의 전 계보를 직접 덮는 범위만 회수·재검증 후 해제하도록 주장·근거·한계를 고쳤다.

## 반론

C-003은 원자료부터 변환·수신·판정까지의 계보와 시간 상한을 사전에 등록하고, 독립
사후 증거가 관찰 전 사용 사건을 직접 덮지 못하면 보류하도록 고쳤다. 그러나 같은
원자료나 근접 변형이 관찰 전후 여러 시간창에서 반복 사용되면, 원자료 식별자와
의미 보존 변환은 내용의 계보만 이어 줄 뿐 어느 사용 사건이 사후 증거의 원인인지
구별하지 못한다. 수신자와 후속 판정자의 기록이 같은 내용을 가리켜도 이전 사용의
잔향을 새 사용으로 기록했거나 여러 사용이 하나의 판정에 합쳐졌을 가능성이 남는다.
따라서 사건별 시간 상한과 독립성 검사가 등록되어도, 다중 사용을 하나의 계보로
합친 경우 관찰 전 사용의 귀속과 보류 범위를 확정할 기준이 아직 없다.

## 해소 조건

C-003은 동일·근접 산출물의 반복 사용과 하나의 판정에 합쳐진 다중 사용을 사건별로
분리할 원자료·수신·판정 표지와 시간·순서 검사를 결과 전에 제시해야 한다. 사건을
분리할 수 없거나 사후 증거가 여러 사용에 공통이면 가능한 사건 묶음과 그에 의존하는
자산·사용·판정을 함께 보류하고, 새 원자료가 특정 사건을 직접 덮는 범위만 해제해야
한다.
