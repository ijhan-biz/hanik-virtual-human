# O-0530 · 의미 스키마의 복구 기록도 의미를 사후 구성할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1542
- 해소: 반복 1543에서 C-003의 주장·근거·한계에 의미 스키마의 변경·폐기·복구 원장과 복구 전후의 유효성 선택·재분류 규칙을 스키마 자체와 독립된 입력으로 등록하고, 복구 불능·상충 버전·사후 보정 후보를 별도 계보로 열거하도록 실제 반영했다. 기준을 공유하지 않는 자료와 양성·음성 대조에서 복구 순서와 유효성 선택을 자극해 잠재 기회 분모와 최악·최선 영향을 산출하며, 제3자 재현 실패 또는 결론 변화에서는 해당 시간창과 토큰 의존 판정을 보류하도록 명시했다.

## 반론

C-003은 식별자 대응·계보 비교·시간창 분류의 의미 스키마와 변경·복구 규칙을
결과와 독립된 입력으로 등록하고, 운영자·권한·정책·복구 계보 및 등록 밖 해석 후보를
별도 열거하도록 고쳤다. 그러나 스키마의 변경·폐기와 복구를 기록하는 원장이 그
스키마로 정의된 식별자, 시간창, 승인 상태를 다시 사용하면 복구 전후의 기준 차이를
표현하지 못할 수 있다. 복구 계보가 보존되어도 어떤 기록이 유효한 기준인지 선택하는
메타 규칙이 사후 결론에 맞춰 바뀌거나, 복구 불능 구간의 재분류가 이미 산출한 분모에
반영되지 않으면 제3자 재현은 같은 사후 의미를 되풀이한다. 따라서 스키마의 복구
기록면과 유효성 선택 규칙까지 독립적으로 검증하지 않으면 토큰 의존 판정은 확정할 수 없다.

## 해소 조건

C-003은 의미 스키마의 변경·폐기·복구 원장과 복구 전후의 유효성 선택·재분류 규칙을
스키마 자체와 독립된 입력으로 등록하고, 복구 불능·상충 버전·사후 보정 후보를 별도
계보로 열거해야 한다. 기준을 공유하지 않는 자료와 양성·음성 대조에서 복구 순서와
유효성 선택을 자극해 잠재 기회 분모와 최악·최선 영향을 산출하고, 제3자 재현 실패
또는 결론 변화에서는 해당 시간창과 토큰 의존 판정을 보류해야 한다.
