# O-0688 · 독립 감사면의 독립성이 봉인된 계보를 다시 전제할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2090
- 해소: 반복 2094에서 C-003의 주장·근거·한계에 감사 자료·부정 대조·대체 기록면별 접근 권한·관측 모집단·공통 계보·사각지대와 감사면 밖 잠재 분모·접근 불능 후보의 별도 산출을 결과 전에 등록하고, 독립성 판정·감사면·부정 대조·누락 분류·집계 순서를 교환해 공통 누락의 발견률·검출 불능률·최악·최선 영향을 산출하도록 실제 반영했다. 제3자 재현 실패나 잔여의 결론 변화 시 해당 진위 검증과 귀속·의존 연속성을 보류한다.

## 반론

C-003은 봉인된 비공유성 계보를 독립 감사 자료·부정 대조·대체 기록면으로 교차 검증하고,
계보 밖 경로와 봉인 누락을 후보로 열거하도록 고쳤다. 그러나 감사 자료와 대체 기록면이 실제
공급자·수집기·접근 통제·전처리 실행을 관측하는 권한과 범위를 갖는다는 전제 자체가 운영자,
자료 공급자, 기록 인프라의 공통 계보에 의존할 수 있다. 부정 대조가 실패해야 드러나는 경로에
접근하지 못하거나, 감사면과 원래 봉인면이 같은 누락 규칙을 공유하면 양쪽의 불일치가 없는
것처럼 보인다. 또한 독립성 판정·자료 경계·누락 분류의 순서를 교환해도 감사 대상의 모집단
밖에 있는 공급과 기록은 생성되지 않는다. 따라서 진위 검증과 후보별 영향 범위를 재현해도
감사면의 포괄 범위 밖 공통 누락이 귀속과 의존 연속성의 결론을 바꾸지 않는다는 보장은 없다.

## 해소 조건

C-003은 독립 감사 자료·부정 대조·대체 기록면 각각의 접근 권한·관측 모집단·공통 계보와
사각지대를 결과 전에 등록하고, 감사면 밖 잠재 분모와 접근 불능 후보를 별도 산출해야 한다.
독립성 판정·감사면·부정 대조·누락 분류·집계 순서를 교환해 감사면 공통 누락의 발견률·검출
불능률·최악·최선 영향을 산출하고, 제3자 재현 실패나 잔여의 결론 변화 시 해당 진위 검증과
귀속·의존 연속성을 보류해야 한다.
