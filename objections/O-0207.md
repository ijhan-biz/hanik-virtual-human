# O-0207 · 독립 계보가 기록되지 않은 의존 산출물까지 역추적하는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0730
- 해소: 반복 0732에서 C-003에 등록 목록과 독립된 자산 발견표를 사전 봉인하고, 별도 저장소·권한·전달 경계의 생성·복제·열람·수정 흔적과 산출물 지문을 대조해 목록 밖 파생물·복제본·수동 해석·외부 전달을 원자료부터 사용처까지 역추적하는 기준을 도입했다. 탐색 경계·식별자·지문 충돌·사용 흔적 시간창·누락률과 판정 규칙을 결과 전에 고정하고, 같은 계보나 접근 기록에 의존하면 독립 발견으로 세지 않도록 했다. 목록의 완전성 또는 사용 흔적을 확인하지 못하면 발견할 수 없는 산출물과 그에 의존하는 후보·영향 범위·책임·동일성 판정을 알려진 산출물만으로 좁히지 않고 보류하며, 독립 기록과 완전한 계보가 직접 덮는 범위만 해제하고 탐색 경계 밖 자산과 의존 판정을 확정할 수 없다는 한계를 실제 반영했다.

## 반론

C-003은 변경 기록이 누락되거나 모순되면 마지막 완전 통과 이후를 통째로 보류하고,
독립 기록자가 후보·영향 셀·변환·이미 해제한 산출물까지 역추적해 비도달이 확인된
것만 제외하도록 고쳤다. 그러나 이 절차가 출발하는 계보표와 산출물 목록 자체가
운영 기록에 등록된 노드와 변환만 포함한다면, 기록 누락으로 인해 등록되지 않은
파생물·복제본·수동 해석·외부 전달을 처음부터 역추적 대상에서 빠뜨릴 수 있다.
독립 기록자가 같은 불완전한 목록을 대조하면 일치성은 확인해도 누락된 의존성을
발견하지 못한다. 마지막 통과 이후를 넓게 보류하는 것은 알려진 산출물의 사용을
막을 뿐, 목록 밖 결과가 이미 해제되어 다른 판정에 들어갔는지까지 보장하지 않는다.
따라서 계보의 완전성을 확인할 독립적인 발견 절차와, 발견되지 않은 산출물의 범위를
어디까지 보류할지 아직 정해지지 않았다.

## 해소 조건

C-003은 등록된 계보·산출물 목록 밖의 파생물·복제본·수동 해석·외부 전달을 찾을
독립적인 자산 발견과 사용 흔적 대조 기준을 사전에 제시해야 한다. 목록의 완전성을
확인하지 못하면 알려진 산출물만 보류했다고 영향 범위를 좁히지 말고, 발견할 수 없는
의존 산출물과 그에 의존하는 판정까지 보류하며, 독립 기록이 없을 때 무엇을 확정할 수
없는지도 밝혀야 한다.
