# O-0504 · 공동 귀속 공간의 제약 등록이 후보 생성의 완전성을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1490
- 해소: 반복 1491에서 C-003의 주장·근거·한계에 공동 귀속 공간에 들어갈 후보의 생성
  규칙과 원자료 분해·관측 해상도 경계를 결과 전에 독립 입력으로 등록하고, 잠재 다중
  사건·다중 귀속·부분 관측의 분할 후보와 등록 밖 잔여를 별도 열거하도록 실제 반영했다.
  후보 생성 경계와 공동 제약을 교란하는 독립 자료, 양성·음성 대조에서 누락 후보·분할·
  공동 극단 조합의 발견 하한을 검증하고, 제3자 재현 실패 또는 등록 밖 후보의 결론 변화에서
  관련 운반 자격·온톨로지 비교·공동 경로 판정을 보류하도록 명시했다.

## 반론

C-003은 등록된 집계와 등록 밖 후보를 하나의 공동 귀속 공간에 넣고, 후보 사이의
상관·배타·중복·부분 관측 제약을 만족하는 실현 가능한 조합만으로 공통 단위별 범위와
보류를 계산하도록 고쳤다. 그러나 공동 공간에 어떤 후보와 제약을 생성할지 정하는 원자료
해석과 관측 해상도가 결과와 독립적으로 완전하다는 보장은 없다. 하나의 기록 안에 관측되지
않은 여러 사건·귀속이 합쳐졌거나, 부분 관측이 후보마다 다른 잠재 단위로 갈라질 수 있으면,
등록된 제약은 열거된 후보들 사이의 일관성만 검사하고 아예 생성되지 않은 조합을 배제한다.

그 상태에서 공동 최악·최선 범위와 제3자 재현은 선택된 후보 공간의 폐쇄성을 재현할 뿐이다.
독립 자료와 양성·음성 대조도 같은 원자료 분해·해상도를 공유하면 숨은 후보를 공동으로
누락할 수 있다. 누락된 귀속이 기존 후보와 상관되거나 서로 배타적이면 실현 가능한 조합의
분모·발견 하한·영향이 달라지고, 운반 자격·온톨로지 비교·공동 경로 판정이 바뀔 수 있다.
따라서 후보 생성의 관측 경계와 잠재 분할을 공동 제약과 별도로 검증하지 않으면, 공동
귀속 공간은 완전성의 증거가 아니라 등록된 후보 목록의 일관성 검사에 머문다.

## 해소 조건

C-003은 공동 귀속 공간에 들어갈 후보의 생성 규칙과 원자료 분해·관측 해상도 경계를 결과
전에 독립 입력으로 등록하고, 기록 내 잠재 다중 사건·다중 귀속·부분 관측의 분할 후보와
등록 밖 잔여를 별도로 열거해야 한다. 각 후보 생성 경계와 공동 제약을 교란하는 독립 자료,
양성·음성 대조에서 누락 후보·분할·공동 극단 조합의 발견 하한을 검증하고, 제3자가 후보
공간·실현 가능 조합·범위·보류를 재현하지 못하거나 등록 밖 후보가 결론을 바꾸면 관련
운반 자격·온톨로지 비교·공동 경로 판정을 보류해야 한다.
