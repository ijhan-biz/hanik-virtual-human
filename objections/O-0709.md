# O-0709 · 중복 제거 대조가 경계 계보의 결합 효과를 숨길 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2185
- 해소: 반복 2194에서 C-003의 주장·근거·한계에 공유 경계의 단독·교차·고차 셀별 종료 지연·식별자 재사용·자원 고갈의 순서와 조건부 경로, 공동 잠재 분모·발견률을 결과와 독립된 입력으로 등록하고, 중복 제거 전후 대조에서 결합 효과의 발견 하한·최악·최선 영향을 산출하도록 실제 반영했다. 교차·고차 셀을 식별·재현하지 못하거나 잔여가 결론을 바꾸면 해당 귀속·계보·연속성을 보류하도록 했다.

## 반론

C-003은 공유 종료 표지·재진입 식별자·자원 경계를 공통 경계 계보로 분리하고, 식별자 재사용·
지연 종료·자원 고갈을 포함한 대안 대조에서 중복 제거 전후의 경로와 잠재 분모를 비교하도록
고쳤다. 그러나 중복 제거 전후를 별도로 산출하는 것만으로는 동일 사건이 여러 경계 계보에
동시에 귀속될 때 생기는 결합 효과를 보존한다고 보장할 수 없다. 종료 지연이 식별자 재사용과
자원 고갈을 함께 유발하면, 각 계보의 중복률은 재현되어도 교차 셀의 경로 순서·공동 분모·
조건부 발견률이 사라질 수 있다. 그러면 공통 누락의 하한과 최악·최선 영향이 계보별 합산으로
과소평가되고, 보류해야 할 귀속이 독립 경계처럼 확정된다.

## 해소 조건

C-003은 공유 경계 계보 사이의 교차·고차 결합 셀에서 종료 지연·식별자 재사용·자원 고갈의
순서와 조건부 경로, 공동 잠재 분모·발견률을 결과와 독립된 입력으로 등록해야 한다. 중복 제거
전후 및 단독·교차·고차 대조에서 결합 효과의 발견 하한·최악·최선 영향을 산출하고, 교차 셀을
식별·재현하지 못하거나 잔여가 결론을 바꾸면 해당 귀속·계보·연속성을 보류해야 한다.
