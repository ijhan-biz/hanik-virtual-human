# O-0541 · 셀별 범위가 결합된 결론 영향까지 닫지 못할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1568
- 해소: 반복 1569에서 C-003의 주장·근거·한계에 셀 사이의 공유 원자료·교정자·경계·보류 전파와 상관·중복·상쇄를 결과 독립 입력으로 등록하고, 가능한 공동 셀 조합의 전체 분모·최악·최선 결론 영향 범위와 중복 제거·보류 전파를 제3자가 재현하지 못하거나 범위가 결론을 바꾸면 셀별 결과와 무관하게 해당 결론을 보류하도록 실제 반영했다.

## 반론

C-003은 불일치·교정 불능 셀을 전체 분모에 사전 등록한 규칙대로 편입하고, 결측·제외·
보류 전파와 유형·시간창별 최악·최선 민감도·오류 범위를 산출하도록 고쳤다. 그러나
셀별 범위를 계산해도 여러 유형·시간창의 미확정 셀이 같은 원자료, 교정자, 시간창 경계,
또는 보류 전파를 공유하면 오류가 독립적으로 더해지거나 상쇄되지 않는다. 셀별 최악·최선
값을 합치거나 각 셀을 따로 보류하는 규칙을 결과를 본 뒤 고르면, 결론을 바꿀 수 있는
공동 범위가 좁혀지거나 중복 계산된다. 제3자가 셀 단위 산출을 재현해도 이런 결합 의존성과
전체 결론의 범위를 재현하지 못할 수 있으므로, 사전 등록된 편입 규칙만으로는 보류가
필요한 결론 영향 범위를 닫았다고 할 수 없다.

## 해소 조건

C-003은 셀 사이의 공유 원자료·교정자·경계·보류 전파와 상관·중복·상쇄를 결과와 독립된
입력으로 등록하고, 가능한 공동 셀 조합의 전체 분모와 최악·최선 결론 영향 범위를
중복 없이 산출해야 한다. 제3자가 결합 규칙·범위·보류 전파를 재현하지 못하거나 그
범위가 결론을 바꾸면 셀별 결과와 무관하게 해당 결론을 보류해야 한다.
