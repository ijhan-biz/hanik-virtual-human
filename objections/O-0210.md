# O-0210 · 비개입 대조가 관찰 전 사용의 계보를 실제로 덮는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0738
- 해소: 반복 0741에서 C-003에 비개입 기록과 독립 사후 사용 증거를 같은 사용 사건으로
  연결하는 원자료·변환·수신·판정 계보와 사건별 시간 상한·독립성 검사를 결과 전에
  등록하고, 원자료 식별자와 의미 보존 변환을 봉인하도록 반영했다. 계보가 관찰 전
  시간창을 직접 덮지 못하거나 사후 증거의 귀속을 가르지 못하면 해당 자산·사용과
  의존 판정을 보류하고, 새 원자료가 계보의 전 구간을 직접 덮는 범위만 해제하도록
  주장·근거·한계와 회수 기준을 고쳤다.

## 반론

C-003은 관찰 전후 비개입 기록과 독립 사후 사용 증거를 비교하고, 개입 효과와
관찰되지 않은 시간창을 분리할 수 없으면 그 시간창을 보류하도록 고쳤다. 그러나
비개입 기록이 남아 있다는 사실은 기록되지 않은 오프라인 생성·삭제·구두 전달이
없었다는 뜻이 아니며, 관찰 뒤에 얻은 수신자 진술도 관찰 전 사용의 원자료·변환·
판정까지 이어지는 계보를 보장하지 않는다. 방문 순서와 음성 대조가 관찰자 효과를
줄여도, 관찰 전 미기록 사용이 독립 사후 증거에 섞였는지 식별하지 못하면 보류
범위의 경계를 정할 수 없다. 따라서 비개입 기록과 사후 증거를 어떤 연결·시간
상한·독립성 기준으로 같은 사용 사건에 귀속할지 아직 정해지지 않았다.

## 해소 조건

C-003은 비개입 기록과 독립 사후 사용 증거를 같은 사용 사건에 연결할 원자료·
변환·수신·판정 계보, 시간 상한, 독립성 검사를 결과 전에 등록해야 한다. 이 계보가
관찰 전 시간창을 직접 덮지 못하거나 사후 증거의 귀속을 가를 수 없으면 해당
사용·자산과 그에 의존하는 판정을 보류하고, 새 원자료가 직접 덮는 범위만 해제해야
한다.
