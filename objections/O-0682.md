# O-0682 · 외부 기준과 잠재 분모의 완전성이 공동 원인 누락을 다시 숨길 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2063
- 해소: 반복 2072에서 C-003의 주장·근거·한계에 외부 기준·잠재 분모의 작성·공급·관측 계보와 공통 누락 경계를 결과 전에 독립 자료로 봉인하고, 기준 밖 공동 소실·미분류·분모 불능을 별도 열거하도록 실제 반영했다. 공통 원인을 공유하지 않는 자료와 양성·음성·모호 대조에서 기준·경계·제약·집계 순서를 교환해 공통 누락의 발견 하한·최악·최선 영향과 미식별 잔여를 산출하며, 제3자 재현 실패나 잔여의 결론 변화 시 해당 귀속과 의존 연속성을 보류한다.

## 반론

C-003은 공유 자원·시간·부모·관측면의 단위와 경계를 결과 전에 독립 자료로 봉인하고,
관측된 불가능·미관측·가능 결합을 외부 기준으로 구별하며 잠재 분모를 별도 등록하도록
고쳤다. 그러나 외부 기준의 작성자·자료 공급자·관측면이 자연 운영과 공통 원인이나 공통
누락을 공유하면, 그 기준은 공동 제약을 발견하기 전에 같은 자원 경합과 부모 소실을
빠뜨릴 수 있다. 잠재 분모를 등록해도 등록 밖에서 함께 사라진 결합은 분모에 들어오지
않으며, 경계·제약·집계 순서의 교환은 공통으로 누락된 셀을 되풀이할 뿐이다. 따라서
발견 하한·최악·최선 범위와 제3자 재현이 일치해도, 외부 기준과 분모 자체의 공동 누락이
동일성 귀속과 의존 연속성의 결론을 바꾸지 않는다는 보장이 아직 없다.

## 해소 조건

C-003은 외부 기준·잠재 분모의 작성·공급·관측 계보와 공통 누락 경계를 결과 전에 독립
자료로 봉인하고, 기준 밖 공동 소실·미분류·분모 불능을 별도 열거해야 한다. 공통 원인을
공유하지 않는 자료와 양성·음성·모호 대조에서 기준·경계·제약·집계 순서를 교환해 공통
누락의 발견 하한·최악·최선 영향과 미식별 잔여를 산출해야 한다. 제3자가 이를 재현하지
못하거나 잔여가 결론을 바꾸면 해당 귀속과 의존 연속성을 보류해야 한다.
