# O-0662 · 운반 검증의 자연 운영 대조가 모델 선택 편향을 놓칠 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2008
- 해소: 반복 2011에서 C-003의 주장·근거·한계에 모델 선택·변경·실패 후 대체의 원인, 선택 전 관측 신호와 선택되지 않은 후보를 결과 독립 입력으로 고정하고 선택 확률·적응 경로·미선택·중도 변경을 별도 생성하도록 실제 반영했다. 독립 양성·음성·모호 대조와 자연 운영에서 모델 선택·대체 순서를 교환해 선택 전후 분포와 모델·층별 공통·고유·운반 불능 분모·발견 하한·최악·최선 영향·미식별 잔여를 분리 산출하며, 제3자가 선택 계보·분모·산출을 재현하지 못하거나 선택 편향 잔여가 결론을 바꾸면 해당 복원 층의 결론과 의존 연속성을 보류한다.

## 반론

C-003은 모델 선택·기준 교환·누락·복구 순서를 자연 운영에서 교환해 모델 간 겹침과 운반
실패를 검출하도록 고쳤다. 그러나 자연 운영의 모델 선택 자체가 복원 가능성, 자원 상태,
사건의 관측 난이도에 따라 결정되면 선택 규칙을 교환한 자료는 실제 선택 확률과 다른
모집단을 만들 수 있다. 선택 시점 전에 관측된 신호가 모델과 후보 층을 동시에 결정하거나,
실패 뒤 모델을 바꾸는 적응이 누락되면 공통·고유·운반 불능 분모의 분리가 선택된 사례에만
성립한다. 따라서 모델 선택·변경의 원인과 선택되지 않은 후보의 잠재 분모, 자연 운영으로
운반할 수 없는 선택 편향의 결론 영향이 아직 닫히지 않았다.

## 해소 조건

C-003은 모델 선택·변경·실패 후 대체의 원인, 선택 전 관측 신호와 선택되지 않은 후보를
결과 독립 입력으로 고정하고, 선택 확률·적응 경로·미선택·중도 변경을 별도 생성해야 한다.
독립 양성·음성·모호 대조와 자연 운영에서 선택·대체 순서를 교환해 선택 전후 분포와 모델·
층별 공통·고유·운반 불능 분모·발견 하한·최악·최선 영향·미식별 잔여를 분리 산출해야 한다.
제3자가 선택 계보·분모·산출을 재현하지 못하거나 선택 편향 잔여가 결론을 바꾸면 해당
복원 층의 결론과 의존 연속성을 보류해야 한다.
