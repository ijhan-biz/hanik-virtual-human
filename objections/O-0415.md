# O-0415 · 복구 전환의 독립 분모도 숨은 외부 부작용의 귀속을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1392
- 해소: 반복 1393에서 C-003의 주장·근거·한계에 실제 적용·회수·공급자 승인·거부·예약 취소·권한 변경처럼 외부 상태나 비가역 부작용을 바꾸는 전환과 내부 보존 요청·재시도·중복 처리·병합·늦은 확인 사이의 인과 규칙을 결과 전에 독립적으로 고정하고, 외부 상태 전환과 내부 전환의 교차 실행 기회를 자연 사건·독립 주입·음성 대조에서 각각 분리해 검출하도록 실제 반영했다. 공급자 승인·거부·예약·권한·지연 반영 경계와 공통 누락 가능성을 별도 검사하고, 외부 전환별 잠재 기회 분모·누락·영향 상한·계보를 내부 기록면과 분리해 제3자가 같은 입력으로 재현하지 못하면 복구 뒤 외부 부작용의 인과 순서·재시도 귀속과 이에 의존하는 서사적 연속성을 확정하지 않도록 명시했다.

## 반론

C-003은 복구·부분 실패·확인 유실에서 보존 요청·새 재시도·중복 처리·병합·늦은
확인의 상태 전이와 인과 귀속을 결과 전에 고정하고, 확인·실제 적용·회수·병합 전환의
교차 실행 기회를 세 대조면에서 분리해 검출하도록 고쳤다. 그러나 실제 적용이나 회수가
외부 공급자·예약·권한·부작용을 바꾸고 그 부작용이 내구 큐와 별도의 경로로 도착한다면,
전환별 분모와 계보를 기록해도 어떤 보존 요청이나 재시도가 외부 상태를 바꾼 원인인지는
결정되지 않을 수 있다. 중복 제거 키로 내부 요청을 병합해도 공급자 쪽에서 이미 발생한
비가역 효과를 병합할 수는 없다.

자연 사건·독립 주입·음성 대조를 각각 분리해도 세 면이 외부 공급자의 승인·거부,
예약 취소·지연 반영 같은 부작용 경계를 공유하면 공통으로 사라진 전환을 놓칠 수 있다.
전환별 잠재 기회와 영향 상한을 분리하는 것만으로는 내부 계보와 외부 상태 전이의
교차 기회를 세지 못하며, 제3자가 같은 입력으로 큐의 인과 순서를 재생해도 외부
부작용의 원인과 재시도 귀속을 확정할 수 없다.

## 해소 조건

C-003은 실제 적용·회수·승인·거부·예약 취소처럼 외부 상태나 비가역 부작용을 바꾸는
전환과 내부 보존 요청·재시도·중복 처리·병합·늦은 확인 사이의 인과 규칙을 결과 전에
독립적으로 고정해야 한다. 외부 상태 전이와 내부 전환의 교차 실행 기회를 자연 사건·
독립 주입·음성 대조에서 각각 분리해 검출하고, 공급자 승인·거부·예약·권한·지연 반영
경계와 공통 누락 가능성을 별도 검사해야 한다. 외부 전환별 잠재 기회 분모·누락·영향
상한·계보를 내부 기록면과 분리해 제3자가 같은 입력으로 재현하지 못하면 복구 뒤
외부 부작용의 인과 순서·재시도 귀속과 이에 의존하는 서사적 연속성을 확정해서는 안 된다.
