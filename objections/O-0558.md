# O-0558 · 경로별 운반 분모가 잠재 경로 공간의 폐쇄를 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1610
- 해소: 반복 1613에서 C-003의 주장·근거·한계에 잠재 경로를 생성·표현·종료하는 상태·언어·시간·자원 범위와 목록 밖 경로의 분류를 결과 독립 입력으로 사전 등록하고, 독립 자료와 양성·음성 대조에서 미표현 상호작용·재진입·관측 불능 경로를 각각 검출하도록 실제 반영했다. 경로 공간의 폐쇄 증거와 경로별 잠재 분모·발견 하한·최악·최선 영향·보류를 산출하며, 제3자 재현 실패나 목록 밖 잔여의 결론 변화 시 해당 운반 자격과 연속성 판정을 보류한다.

## 반론

C-003은 주입과 자연 사건의 잠재 생성 경로, 개입 효과, 관측되지 않은 결과와 양의 지지
조건을 결과 독립 입력으로 등록하고, 경로별 운반 가능 분모와 발견 하한을 산출하도록
고쳤다. 그러나 어떤 경로를 잠재 경로로 열거할 수 있는지는 등록된 상태·언어·시간 범위와
탐색 절차에 의존한다. 주입 제거·순서 교환·경쟁 경로 차단으로 드러나는 경로만 대조하면,
아직 표현되지 않은 상호작용이나 재진입 경로는 경로별 분모에 들어오지 않는다. 그 잔여가
관측되지 않은 결과로만 나타나면 양성·음성 대조의 검출 하한도 함께 닫히지 않는다. 따라서
경로별 산출을 제3자가 재현해도 잠재 경로 공간의 폐쇄와 목록 밖 경로의 영향까지 보장하지
못하며, 운반 자격과 연속성 판정을 확정할 수 없다.

## 해소 조건

C-003은 잠재 경로를 생성·표현·종료하는 상태·언어·시간·자원 범위와 목록 밖 경로의
분류를 결과 독립 입력으로 사전 등록하고, 독립 자료와 양성·음성 대조에서 미표현
상호작용·재진입·관측 불능 경로를 각각 검출해야 한다. 경로 공간의 폐쇄 증거와 경로별
잠재 분모·발견 하한·최악·최선 영향·보류를 산출하고, 제3자 재현 실패나 잔여의 결론
변화 시 해당 운반 자격과 연속성 판정을 보류해야 한다.
