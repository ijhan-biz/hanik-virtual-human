# O-0667 · 소실률의 잠재 의존성이 단계 교환의 식별을 가릴 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2015
- 해소: 반복 2025에서 C-003의 주장·근거·한계에 소실 전·후 잠재 상태와 결과를 함께 검증할 독립 회수 표본 또는 외부 기준을 결과 전에 사전 등록하고, 소실률의 공변량별 결합분포와 비회수 후보의 잠재 분모를 별도 산출하도록 실제 반영했다. 회수 가능·불능·모호 대조에서 소실 단계·계보와 모델 선택·대체 순서를 교환해 범위를 좁히며, 제3자 재현 실패나 잔여 범위의 결론 변화 시 상태 귀속과 연속성을 보류한다.

## 반론

C-003은 권한 중단·재시도·큐 탈락·관측면 변경과 기록 소실을 단계별 독립 입력으로
등록하고, 각 단계의 잠재 분모와 미관측 생성률을 사전 고정하도록 고쳤다. 그러나
소실률 자체가 전환 이전 신호, 상태 선택, 이후 진입 가능성에 의존하면 관측된 소실
계보와 독립 대조의 교환은 이미 살아남은 후보의 비율만 바꿀 수 있다. 단계별
미관측 생성률을 고정해도 소실 전후의 결합 잠재분포나 회수되지 않은 후보의 결과를
검증할 기준이 없으면 상태 선택과 기록 소실의 구별이 여전히 가정에 의존한다.
따라서 소실 단계 교환과 분리 산출만으로 결론의 식별 가능성이 닫혔다고 할 수 없다.
이는 결과 독립성의 증명이 아니다.

## 해소 조건

C-003은 소실 전·후 잠재 상태와 결과를 함께 검증할 독립 회수 표본 또는 외부 기준을
사전 등록하고, 소실률의 공변량별 결합분포와 비회수 후보의 잠재 분모를 별도 산출해야
한다. 회수 가능·불능·모호 대조에서 이를 교환해 범위를 좁히고, 제3자 재현 실패나
잔여 범위의 결론 변화 시 상태 귀속과 연속성을 보류해야 한다.
