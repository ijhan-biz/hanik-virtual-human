# O-0517 · 교차 계보의 관측 단위가 경계 간 전파를 완전히 분해하지 못한다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1503
- 해소: 반복 1504에서 C-003의 주장·근거·한계에 교차 계보의 관측 단위와 경계 상태 전이를
  잇는 식별자 대응, 원자적 분할·병합·중복 제거 규칙을 결과 독립 입력으로 고정하고, 전파의
  시작·중간·종료와 관측 불능 후보를 별도 계보로 분리해 실제 반영했다. 독립 자료와
  양성·음성 대조에서 경계별 단독·결합·순서 교란을 검증하고 후보 조합·순서별 도달 가능성,
  검출 하한·잠재 분모·누락·최악·최선 영향을 산출하도록 했으며, 제3자 재현 실패 또는
  범위의 결론 변화에서 해당 시간창과 교차 계보 의존 판정을 보류하도록 명시했다.

## 반론

C-003은 공유 경계마다 상태 전이의 선후·동시성·전파 지연·재진입을 계보 입력으로
등록하고, 한 경계의 갱신이 다른 경계의 자격·접근·기록 가능성을 바꾸는 단독·결합·
순서 교란을 독립 자료와 양성·음성 대조에서 검증하도록 고쳤다. 그러나 경계별 상태
전이와 교차 전파를 기록하는 관측 단위가 서로 다르거나 한 전이가 여러 경계의 내부
상태를 원자적으로 바꾸면, 동일한 전파가 여러 계보 사건으로 중복 기록되거나 어느
경계에서 시작했는지 관측되지 않을 수 있다.

독립 자료와 양성·음성 대조가 각 경계의 단독·결합·순서 교란을 실제로 자극해도,
경계 간 전파의 원자성·분할·병합·중복 제거 규칙이 결과 이후에 선택되면 후보 조합·
순서별 실제 도달 가능성과 잠재 분모가 같은 자료에 맞춰진다. 제3자가 등록된 상태
전이와 전파를 재현해도, 관측 단위 사이의 식별자 대응·중복·누락·원자성의 범위를
닫지 못하면 원인별 분리와 교차 계보 결론을 확정할 수 없다.

## 해소 조건

C-003은 경계 간 상태 전이와 전파를 연결하는 관측 단위·식별자 대응, 원자적 분할·
병합·중복 제거 규칙을 결과와 독립된 입력으로 등록하고, 전파의 시작·중간·종료 및
관측 불능 후보를 계보에서 분리해야 한다. 독립 자료와 양성·음성 대조에서 경계별
단독·결합·순서 교란의 전파를 각각 검증하고, 후보 조합·순서별 실제 도달 가능성·
검출 하한·잠재 분모·누락·최악·최선 영향을 제3자가 재현해야 한다. 이 대응·원자성·
중복·누락 범위를 재현하지 못하거나 범위가 결론을 바꾸면 해당 시간창과 교차 계보
의존 판정을 보류해야 한다.
