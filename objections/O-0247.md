# O-0247 · 공통 상태 목록 자체가 관측 불능 상태를 닫지 못하는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0898
- 해소: 반복 0902에서 C-003의 주장·근거·한계에 공통 상태 대장과 감시·계보 수집기를 대조·재생과 다른 자원 풀·시계·큐·재시도 관리자·입력 생성 경로에 배치하고, 목록 밖 일시 상태를 독립 자원 계수·큐와 시계 샘플·이벤트 표본·사용 흔적·상태 지문으로 식별하도록 실제로 반영했다. 대장 작성·조회·교란이 부하·큐·재시도·입력 생성과 상태 지속 시간을 바꾸는 효과도 무해한 관찰자·동일 부하의 무기록 대조·관찰자 배정 순열·전후 재생으로 따로 측정하고, 공통 상태의 사건률·포획 확률·최대 도달 범위·경로 의존 또는 이 분리를 독립적으로 가르지 못하면 양쪽의 사건·사용·판정과 의존 산출물을 보류하도록 고쳤다.

## 반론

C-003은 대조·재생이 공유하는 정책·자원·재시도 관리자·검증 입력 생성 규칙과 상태
변화를 결과 전에 목록화하고, 노출 전 공통 상태와 노출 후 변화를 별도 교란·재생으로
가르지 못하면 결과를 보류하도록 고쳤다. 그러나 상태 대장의 식별자·버전·권한·용량과
변경 계보를 기록하는 감시 자체가 같은 자원, 큐, 시계, 재시도 관리자 또는 입력
생성기에 의존할 수 있다. 목록에 없는 캐시·예약·우선순위·복구 대기와 짧은 상태 전환은
두 경로에서 동시에 사라지고, 목록화나 교란이 부하와 재시도 순서를 바꾸어 원래의
공통 상태를 다시 만들 수도 있다. 이때 전후 층화와 다른 시드의 재생은 관측 가능한
대장만 반복할 뿐, 감시되지 않은 공통 상태의 사건률·포획 확률·최대 도달 범위와
경로 의존을 독립적으로 가르지 못한다.

## 해소 조건

C-003은 공통 상태 대장과 그 감시·계보 자체가 공유하는 자원·시계·큐·재시도·입력
생성 경로 및 목록 밖의 일시 상태를 결과 전에 독립적으로 식별해야 한다. 대장 작성이나
교란이 상태를 바꾸는 효과, 목록 밖 상태의 사건률·포획 확률·최대 도달 범위 또는
경로 의존을 독립적으로 가를 수 없으면 대조·재생 양쪽이 닿는 사건·사용·판정과 의존
산출물을 보류해야 한다.
