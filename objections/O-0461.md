# O-0461 · 전환 유형의 사전 등록이 환경 상태의 동시 결합을 닫는다는 보장이 없다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1446
- 해소: 반복 1447에서 C-003의 주장·근거·한계에 동시·순차·부분 적용·재시도되는 변경의
  조합을 결과 전에 유한하게 등록하고, 조합별 원자성·선형화 순서·간격·유효 기간과 경로
  생성·종료 규칙을 봉인하도록 실제 반영했다. 등록 밖 순서·간격·부분 상태·재시도를 미등록
  잔여로 분리하고, 독립 자료와 양성·음성 대조로 조합별 폐쇄성·잔여 상한·계보를 전환
  전후에 다시 검증하도록 했다. 제3자가 같은 입력으로 조합과 보류 셀을 재현하지 못하거나
  조합별 범위가 결론을 뒤집으면 해당 조합과 의존 판정을 보류하도록 명시했다.

## 반론

C-003은 버전·자원·공급자·부하·정책·권한 상태의 변경을 전환 유형으로 등록하고,
전환 전후에 단독·결합·재결합 경로와 폐쇄성·잔여 상한을 다시 검증하도록 고쳤다. 그러나
각 상태의 변경을 유형별로 나누어 재검증하는 것만으로는 여러 변경이 같은 전환 구간에서
동시에 일어나거나 서로의 경로 생성률과 종료 가능성을 바꾸는 경우를 포괄하지 못한다.
예를 들어 공급자 전환이 자원 포화를 만들고 그 포화가 권한 재시도와 정책 선택을
변경하면, 단독 전환과 각 쌍의 대조가 모두 닫혀도 세 상태의 순서·간격·공동 이력이
새 경로를 만들 수 있다.

전환 시점과 유효 기간을 봉인해도 상태 변화가 원자적으로 함께 적용되었는지, 부분 적용과
재시도가 어떤 상태 조합을 실제로 통과했는지 식별하지 못하면 전후 계보는 분석자가
정한 경계의 산물일 수 있다. 독립 대조와 양성 노출이 각 전환 유형을 다시 자극해도
동시 결합의 잠재 기회 분모·누락·영향 상한을 별도로 닫지 못하면, 이전 폐쇄성을
운반하지 않는 보수적 보류 규칙이 어떤 셀에 적용되어야 하는지조차 재현되지 않는다.

## 해소 조건

C-003은 동시·순차·부분 적용·재시도되는 전환 조합을 결과 전에 유한하게 등록하고,
조합별 원자성·순서·간격·유효 기간과 경로 생성·종료 규칙을 봉인해야 한다. 독립 자료와
양성·음성 대조에서 조합별 폐쇄성·잔여 상한·계보를 재검증하고, 제3자가 같은 입력으로
조합과 보류 셀을 재현하지 못하거나 범위가 결론을 뒤집으면 해당 조합과 의존 판정을 보류해야 한다.
