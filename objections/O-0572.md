# O-0572 · 후보 생성 범위가 관측 경계 밖의 분포 변화를 식별하지 못할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1644
- 해소: 반복 1645에서 C-003의 주장·근거·한계에 후보 생성 범위가 적용되는 측정면·운영 분포·전이 규칙과 등록 밖 상호작용을 결과 독립 입력으로 사전 등록하고, 경계 전후 독립 자료와 양성·음성 대조에서 측정·분포 전이와 등록 밖 상호작용을 검출하도록 실제 반영했다. 전이별·층화별 잔여의 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 산출하며 제3자가 경계 전이·산출·보류를 재현하지 못하거나 범위가 결론을 바꾸면 해당 셀과 의존하는 운반·귀속·연속성 판정을 보류한다.

## 반론

C-003은 대안 층화 후보와 고차원 교차·연속 꼬리의 생성 범위 및 후보 밖 잔여를
결과와 독립된 입력으로 등록하고, 독립 자료와 양성·음성 대조에서 잔여의 지지 결손과
관측 경계 누락을 검출하도록 고쳤다. 그러나 후보 생성 범위와 잔여의 잠재 분모는
관측된 공변량과 동일한 측정면·운영 분포가 실제 실행에도 유지된다는 전제에 의존한다.
측정 장치·사용자 구성·정책이 바뀌거나 등록된 공변량 밖의 상호작용이 생기면, 그 변화는
잔여 후보로 표현되지 않은 채 기존 셀의 양의 지지로 집계될 수 있다. 독립 자료가 같은
경계를 공유하면 제3자 재현도 그 누락을 반복한다. 따라서 후보 공간의 폐쇄를 확인해도
분포·측정 경계의 전이와 그로 인한 운반 자격의 변화를 식별했다고 확정할 수 없다.

## 해소 조건

C-003은 후보 생성 범위가 적용되는 측정면·운영 분포·전이 규칙과 등록 밖 상호작용을
결과 독립 입력으로 사전 등록해야 한다. 경계 전후의 독립 자료와 양성·음성 대조에서
측정·분포 전이와 등록 밖 상호작용을 검출하고, 전이별 잠재 분모·식별 가능성 하한·
최악·최선 영향·보류 전파를 산출해야 한다. 제3자가 경계 전이와 산출을 재현하지 못하거나
범위가 결론을 바꾸면 해당 셀과 의존하는 운반·연속성 판정을 보류해야 한다.
