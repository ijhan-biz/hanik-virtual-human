# O-0387 · 셀 재분할이 검출 가능한 혼합만 다룰 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1363
- 해소: 반복 1364에서 C-003의 주장·근거·한계에 등록된 자료·교란으로 식별 가능한
  혼합과 식별 불가능한 혼합을 구분하고, 후자의 가능한 선택 규칙 집합을 결과 전에
  명시하도록 실제 반영했다. 식별 불가능한 각 규칙에 대한 공통 지지·분모·전이·생성률·
  누락·영향·운반 가중치의 최악 범위를 원자료·계보에서 산출해 제3자가 같은 입력으로
  재현하고 유한하게 닫을 때만 셀을 인정하며, 규칙 집합이나 범위를 봉인·재현·유한하게
  닫지 못하면 해당 셀과 의존하는 운반·동일성·완전성 판정을 보류하도록 명시했다.

## 반론

C-003은 이력·사건·선택 상태의 표현과 셀 경계를 결과 전에 고정하고, 독립 자료와
교란으로 셀 내부의 숨은 혼합·분할 실패를 검출하며, 검출되면 공통 지지와 분모·전이·
생성률·누락·영향 상한·운반 가중치를 재계산하도록 고쳤다. 그러나 독립 자료와 등록된
교란이 구분해 내는 혼합만 검출 가능하다는 보장이 없으면, 두 개의 서로 다른 숨은 선택
규칙이 모든 관측된 자료에서 같은 분포를 만들 수 있다. 그 경우 재분할 절차가 같은 입력으로
재현되고 각 상한이 유한해도, 검출되지 않은 혼합이 공통 지지와 운반 가중치를 바꾸는 최악
영향은 계산에 들어오지 않는다. 보류 규칙은 닫을 수 없는 혼합을 정직하게 남길 뿐, 닫힌
셀의 결합률이 자연 운영에 운반 가능한 이유를 아직 보장하지 않는다.

## 해소 조건

C-003은 등록된 자료·교란으로 식별 가능한 혼합과 식별 불가능한 혼합을 구분하고, 후자의
가능한 선택 규칙 집합과 공통 지지·분모·전이·생성률·누락·영향·운반 가중치의 최악 범위를
결과 전에 정해야 한다. 그 식별 가능성 또는 최악 범위를 제3자가 같은 입력으로 재현해
유한하게 닫지 못하면 해당 셀과 의존하는 운반·동일성·완전성 판정을 보류해야 한다.
