# O-0672 · 잠재 후보 우주의 단위 고정이 생성기 경계를 전제할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2032
- 해소: 반복 2034에서 C-003의 주장·근거·한계에 잠재 후보 우주의 단위·생성기 경계·동일성 규칙을 결과 독립 입력으로 고정하고, 서로 다른 단위화·경계의 독립 대안에서 공통·고유 후보와 미생성 경로·잠재 분모를 분리 열거하도록 실제 반영했다. 자연 운영 및 독립 양성·음성·모호 대조에서 단위화·경계·교환 순서를 교차해 대안별 발견 하한·최악·최선 영향·미식별 잔여를 산출하며, 제3자 재현 실패나 공통 누락·대안 잔여의 결론 변화 시 해당 생성 계보와 의존 연속성을 보류한다.

## 반론

C-003은 생성기 입력·피드백·자원 상태와 잠재 후보 우주의 단위를 결과 독립으로 고정하고,
동일 우주 안의 교환과 우주가 달라지는 교환을 분리하도록 고쳤다. 그러나 잠재 우주의
단위와 생성기 경계를 정하는 식별자·동일성 규칙이 생성기 자체의 산출이나 관측 가능한
후보에 의존하면, 우주를 사전 고정했다는 기록은 생성되지 않은 후보를 애초에 바깥으로
밀어낼 수 있다. 서로 다른 단위화가 같은 관측 후보를 공유하면서 미생성 경로와 분모를
다르게 만들면, 제3자가 한 단위화와 교환 산출을 재현해도 우주가 완전히 열렸다는 결론은
검증되지 않는다. 따라서 동일 우주/우주 변경의 분리와 미생성 경로 열거가 단위화 선택의
공동 누락을 운반 불능 잔여로 남긴다는 보장은 아직 없다.

## 해소 조건

C-003은 잠재 후보 우주의 단위·생성기 경계·동일성 규칙을 결과 독립 입력으로 고정하되,
서로 다른 단위화와 생성기 경계를 만드는 독립 대안에서 공통·고유 후보, 미생성 경로와
잠재 분모를 분리 열거해야 한다. 자연 운영 및 독립 양성·음성·모호 대조에서 단위화·경계·
교환 순서를 교차해 각 대안의 발견 하한·최악·최선 영향·미식별 잔여를 산출해야 한다.
제3자가 공통 누락과 산출을 재현하지 못하거나 대안 단위화의 잔여가 결론을 바꾸면 해당
생성 계보와 의존 연속성을 보류해야 한다.
