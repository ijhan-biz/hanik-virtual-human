# O-0545 · 재진입 계보가 반복 관측을 새 상태로 잘못 셀 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1581
- 해소: 반복 1584에서 C-003의 주장·근거·한계에 재진입·지연 관측을 구분하는 상태 동일성·식별자 대응·원자료 공유·시간창 경계의 불변식과 중복 제거 규칙을 결과 독립 입력으로 등록하고, 보류 해소 전후 재관측·실제 분기·동일 상태 반복을 독립 자료·양성·음성 대조에서 생성해 병합·분리별 누락 분모·최악·최선 영향·보류를 추적하도록 실제 반영했다. 제3자 재현 실패 또는 병합·분리 선택에 따른 결론 변화 시 해당 결론을 보류한다.

## 반론

C-003은 경계 밖 조합과 순차 보류가 다음 시간창에 만드는 후속 재진입을 별도 계보로
생성·추적하고, 전체 누락 분모와 영향 범위를 산출하도록 고쳤다. 그러나 같은 잠재
상태가 보류 전파 때문에 다시 관측되는 경우, 재진입을 새 상태 전이로 세는지 기존
상태의 지연 관측으로 병합하는지는 식별자 대응과 시간창 경계만으로 결정되지 않는다.
두 계보를 병합하면 실제 분기·재진입을 누락할 수 있고, 분리하면 하나의 전이를 여러
번 세어 분모와 결론 함수의 임계값을 왜곡할 수 있다. 특히 보류의 원인이 해소된 뒤
재관측된 상태가 이전 관측과 일부 원자료를 공유하면, 독립 자료·양성·음성 대조가
재진입 자체는 재현해도 중복 제거와 상태 동일성의 기준을 검증하지 못할 수 있다.

## 해소 조건

C-003은 재진입과 지연 관측을 구분하는 상태 동일성·식별자 대응·원자료 공유·시간창
경계의 불변식과 중복 제거 규칙을 결과와 독립된 입력으로 등록해야 한다. 보류 해소 전후의
재관측, 실제 분기, 동일 상태의 반복 관측을 독립 자료·양성·음성 대조에서 각각 생성해
병합·분리 결과, 누락 분모·최악·최선 영향·보류를 추적해야 한다. 제3자가 상태 동일성,
중복 제거, 보류 전파를 재현하지 못하거나 병합·분리 선택이 결론을 바꾸면 해당 결론을
보류해야 한다.
