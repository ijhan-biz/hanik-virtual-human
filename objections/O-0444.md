# O-0444 · 외부 효과의 확인이 하위 연쇄의 실제 종료를 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1428
- 해소: 반복 1429에서 C-003의 주장·근거·한계에 상위 외부 효과의 확인·보상 뒤에 연결되는 웹훅·구독자·하위 큐·정산·권한 회수의 수신·적용·중복·재시도·되돌림과 유한한 단말 상태를 결과 전에 별도 봉인하도록 실제 반영했다. 하류 연쇄의 잠재 기회 분모·생성률·최대 영향·부모-자식 회수 계보를 상위 효과 및 내부 커밋 수치와 분리하고, 독립 교란에서 하위 승인·거부·예약·회수와 보상 실패를 검증하며, 제3자가 상위 확인부터 하류 커밋·보류와 유한한 종료까지 같은 입력으로 재현하지 못하면 외부 효과에 의존하는 귀속·연속성을 확정하지 않도록 명시했다.

## 반론

C-003은 내부 원자적 전환을 외부 공급자·권한 중재기·큐·캐시의 효과 수신·적용·
확인·멱등성·보상 경계와 함께 봉인하고, 외부 효과의 커밋·확인·보류를 독립 교란에서
재현하지 못하면 전환 잔여와 귀속을 확정하지 않도록 고쳤다. 그러나 공급자의 확인이나
보상 완료가 그 공급자 이후의 웹훅·구독자·하위 큐·정산·권한 회수 같은 비동기 효과까지
실제로 끝났다는 뜻은 아니다. 확인이 성공한 뒤 하위 소비자가 중복 적용하거나, 보상
메시지가 지연·유실된 채 새로운 하위 사건을 만들면, 봉인된 효과 경계 안에서는 커밋과
보류가 재현되어도 외부에 남은 결과와 내부 부모-자식 계보가 갈라진다.

하위 공급자와 소비자의 승인·거부·예약·회수·재시도 및 종료를 같은 입력으로 재현하지
않고 상위 확인만 신뢰하면, 하위 연쇄의 잠재 기회 분모·생성률·최대 영향·회수 계보를
내부 커밋 수치와 분리해 닫을 수 없다. 따라서 확인·보상 경계의 하류 효과를 독립
교란에서 검증하고 유한한 단말 상태까지 회수하지 않으면 C-003은 외부 효과에 의존하는
변경 전후 귀속과 연속성을 확정할 수 없다.

## 해소 조건

C-003은 외부 효과의 확인·보상 뒤에 연결되는 웹훅·구독자·하위 큐·정산·권한 회수 등
하류 효과의 수신·적용·중복·재시도·되돌림·종료 경계를 결과 전에 별도로 봉인해야 한다.
하류 연쇄의 잠재 기회 분모·생성률·최대 영향·부모-자식 회수 계보를 상위 효과와 내부
커밋 수치에서 분리해 산출하고, 독립 교란에서 하위 승인·거부·예약·회수와 보상 실패를
검증해야 한다. 제3자가 같은 입력으로 상위 확인부터 하위 효과의 커밋·보류와 유한한
단말 상태까지 재현하지 못하면 외부 효과에 의존하는 귀속·연속성을 확정하지 않아야 한다.
