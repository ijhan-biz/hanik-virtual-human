# O-0747 · 등록 밖 탐색의 종료 기준이 대안 공간의 완전성을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2349
- 해소: 반복 2359에서 C-003에 탐색 순서·종료 기준, 측정면 간 후보의 중복 제거·병합 규칙,
  공통 사각지대의 미발견 대안을 검출하는 결과 독립 교란·재표집 경로를 사전 등록하고,
  탐색 순서·종료별 미포괄 후보의 발견 하한·공동 잠재 분모·부분식별 범위와 최악·최선을
  산출하도록 반영함. 완전성을 식별하지 못하거나 범위가 결론을 바꾸면 해당 층의 운반·
  귀속·계보·연속성을 보류하도록 함.

## 반론

C-003은 귀속 대안 공간의 완전성 기준과 등록 밖 고차 원인·측정면 선택 경로를 찾는 독립
탐색을 고정하고, 미포괄 대안의 발견 하한·공동 잠재 분모·조건부·주변 estimand·부분식별
범위를 산출하도록 고쳤다. 그러나 탐색이 언제 충분한지, 서로 다른 측정면의 탐색 결과를
어떻게 중복 제거하고 하나의 잠재 대안으로 묶는지의 기준이 완전성 기준 자체에 의존하면,
발견되지 않은 고차 결합은 하한에 포함되지 않을 수 있다. 탐색을 계속해도 새로운 대안을
발견하지 못한 결과는 탐색 면의 공통 사각지대와 구별되지 않으므로, 등록 밖 후보의 범위와
보류 규칙만으로 대안 공간이 완전하다는 결론을 식별할 수 없다.

## 해소 조건

C-003은 탐색 종료 기준, 측정면 간 후보의 중복 제거·병합 규칙, 공통 사각지대에서 미발견
대안을 검출하는 독립 교란·재표집 경로를 결과 독립 입력으로 사전 등록해야 한다. 탐색
순서·종료별 미포괄 후보의 발견 하한·공동 잠재 분모·부분식별 범위와 최악·최선을 산출하고,
완전성을 식별하지 못하거나 범위가 결론을 바꾸면 해당 층의 운반·귀속·계보·연속성을
보류해야 한다.
