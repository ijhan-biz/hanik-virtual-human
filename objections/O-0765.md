# O-0765 · 공동 분모의 대조 가능성이 부모별 귀속의 불변성을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2433
- 해소: 반복 2462에서 C-003의 주장·근거·한계에 다중 부모·공유 후속 귀속 대안마다 부모별 생성 원인·자원 기여와 관측 전 잠재 노출·선택·귀속의 공동 분모를 구분한 결과 독립 입력, 독립 양성·음성·모호 대조와 자연 계보의 원인·자원 기여 결합 및 주변·조건부 estimand, 최악·최선 범위를 실제 반영했다. 동일 관측 대안이 부모별 운반 결론을 식별하지 못하면 해당 귀속·계보·연속성을 보류한다.

## 반론

C-003은 다중 부모·공유 후속의 귀속 대안마다 부모별 잠재 노출·선택·귀속의 공동
분모를 두고, 정규화·중복·순서 규칙과 가중 식별 불능 대안을 대조와 자연 계보에서
비교하도록 고쳤다. 그러나 각 부모의 공동 분모를 같은 기준으로 산출해도 부모들이
공유하는 후속의 생성 원인과 자원 기여가 서로 대체 가능한지는 보장되지 않는다.
동일한 공동 분모와 동일한 총 가중을 유지한 채 한 부모의 잠재 기여를 다른 부모의
관측 전 단계 기여와 교환하면, 귀속 대안은 같은 주변 선택확률과 결론을 낼 수 있다.
그 경우 최악·최선 범위가 결론을 바꾸지 않는다는 것만으로는 어느 부모의 계보가
실제로 운반되었는지 식별할 수 없다.

## 해소 조건

C-003은 다중 부모·공유 후속의 귀속 대안마다 부모별 생성 원인·자원 기여와 관측 전
잠재 노출·선택·귀속의 공동 분모를 구분해 결과 독립 입력으로 등록해야 한다. 독립
양성·음성·모호 대조와 자연 계보에서 대안마다 원인·자원 기여의 결합과 주변·조건부
estimand를 교차 산출하고, 동일 관측을 만드는 대안의 최악·최선 범위가 부모별
운반 결론을 식별하지 못하면 해당 귀속·계보·연속성을 보류해야 한다.
