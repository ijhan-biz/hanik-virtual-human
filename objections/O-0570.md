# O-0570 · 지지 겹침 판정의 층화가 잠재 분모를 가릴 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1642
- 해소: 반복 1643에서 C-003의 주장·근거·한계에 공변량 층화의 단위·경계, 희귀층 병합, 연속 공변량 구간화 규칙·분해능과 개입·비개입 양의 지지·중간 상태 관측 가능성·자연 운영·독립 자료의 지지 겹침 규칙을 결과 독립 입력으로 사전 등록하고, 독립 자료와 양성·음성 대조에서 분해능 안팎의 지지 밖 층·층 내부 결손·중간 상태 선택·절단·재가중 후보를 검출하도록 실제 반영했다. 원·대안 층화별 잠재 분모·식별 가능성 하한·최악·최선 영향·보류 전파를 산출하며 층화·검출·보정 범위의 제3자 재현 실패나 숨은 지지 결손의 결론 변경 시 해당 셀과 의존 판정을 보류한다.

## 반론

C-003은 개입 전 공변량별 양의 지지와 자연 운영·독립 자료의 지지 겹침을 사전 등록하고,
지지 밖 층과 관측 불능 중간 상태를 검출해 층별 잠재 분모와 식별 가능성 하한을 산출하도록
고쳤다. 그러나 공변량을 어떤 단위와 경계로 층화할지는 운영 분포와 결과를 보기 전에도
여러 방식으로 정할 수 있고, 희귀 층을 합치거나 연속 공변량을 구간화하면 개입·비개입의
지지가 없는 하위 집단이 겹침이 있는 층 안에 숨을 수 있다. 독립 자료와 대조가 같은
사전 층화를 재현해도 그 분해능 아래의 지지 결손과 중간 상태 선택을 검출하지 못할 수
있으므로, 층별 보류 범위만으로 전체 셀의 운반 자격을 확정할 수 없다.

## 해소 조건

C-003은 지지 겹침을 판정할 공변량의 단위·경계·희귀층 병합·연속 공변량 구간화 규칙과
분해능을 결과와 독립된 입력으로 사전 등록해야 한다. 독립 자료와 양성·음성 대조에서
등록된 분해능 안팎의 지지 결손·중간 상태 선택을 검출하고, 대안 층화별 잠재 분모·식별
가능성 하한·최악·최선 영향·보류 전파를 산출해야 한다. 제3자가 층화·검출·보정 범위를
재현하지 못하거나 숨은 지지 결손의 범위가 결론을 바꾸면 해당 셀과 의존 판정을 보류해야 한다.
