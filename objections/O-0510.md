# O-0510 · 확장 함수의 등록된 입력 도메인이 외부 상태 변화를 닫는다는 보장이 없다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1496
- 해소: 반복 1497에서 C-003의 주장·근거·한계에 외부 공급자의 정책 버전·정책 변경,
  권한 회수·승격, 자원 재배정, 복구 상태와 전이 규칙을 포함한 확장 함수 입력 도메인의
  완전성 경계를 결과와 독립된 자료로 등록하고, 등록 밖 상태의 잠재 기회 분모·발견 하한·
  최악·최선 영향을 독립 자료와 양성·음성 대조에서 검증하도록 실제 반영했다. 제3자가
  경계·확장·종료·보류를 재현하지 못하거나 등록 밖 상태가 결론을 바꾸면 관련 판정을
  보류하도록 명시했다.

## 반론

C-003은 고차 관계 경계의 확장 함수를 입력 도메인·자원·권한·공급자·복구 불변식에서
결과와 독립된 유한 함수로 도출하고, 확장 전후의 상태·계보와 동시·순차·재진입 조합을
기록하도록 고쳤다. 그러나 그 입력 도메인과 전이 규칙 자체가 외부 공급자의 정책 변경,
권한 회수·승격, 자원 재배정, 또는 기록되지 않은 복구 상태를 모두 표현한다는 보장은
추가되지 않았다. 확장 함수가 등록된 도메인 안에서는 유한하게 종료해도, 도메인 밖의
상태가 새로운 관계·재진입·배타 제약을 만들면 함수는 실제 경계의 꼬리를 계산하지 않는다.

독립 자료와 양성·음성 대조가 등록된 상태·공급자·복구 조합을 모두 노출해도 외부 상태
변화가 대조와 본 자료에 함께 누락되면 같은 발견 하한을 공유한다. 제3자가 확장·종료·
보류 절차를 재현하는 것도 등록된 입력에 대한 재현일 뿐, 등록 밖 상태의 잠재 기회
분모와 최악·최선 영향을 닫았다는 증거가 아니다. 그런 꼬리가 결론을 바꿀 수 있는 동안
관계 그래프와 그에 의존하는 귀속·연속성 판정을 확정할 수 없다.

## 해소 조건

C-003은 외부 공급자·정책 변경·권한 변화·자원 재배정·복구 상태를 포함한 확장 함수의
입력 도메인과 전이 규칙의 완전성 경계를 결과와 독립된 자료로 등록해야 한다. 등록 밖
상태의 잠재 기회 분모·발견 하한·최악·최선 영향을 독립 자료와 양성·음성 대조에서
검증하고, 제3자가 그 경계·확장·종료·보류를 재현하지 못하거나 등록 밖 상태가 결론을
바꾸면 관련 판정을 보류해야 한다.
