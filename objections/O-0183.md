# O-0183 · 출처 대장이 영향의 반사실을 복원하는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0633
- 해소: 반복 0636에서 C-003에 질적 기록의 노출과 선택 변경을 봉인한 동시적 열람·
  결정·자원·설계 기록으로 남기고, 원자료를 보지 않은 독립 기록자가 노출 전 등록
  대안의 실행 가능성·다른 정보·제약의 설명력을 항목별 대조하도록 했다. 비공식
  경로·미선택 대안을 관측할 수 없거나 경쟁 원인을 분리할 수 없으면 영향 범위를
  확정하지 않고 선택·의존 산출물·동일성·방향·수치·우선순위·관측 설계를 격리·
  보류하며, 누락 경로·대조 불능 대안·남은 원인별 설명을 원문 위치와 함께 불확실성
  목록에 기록하도록 주장·근거·한계에 실제 반영했다.

## 반론

C-003은 회의·자원 배분·조사 설계의 이력과 질적 기록의 열람 시점을 별도 출처
대장에 남기고, 독립 기록자가 선택 전후의 대안과 절차적 경로를 대조하도록 고쳤다.
그러나 회의록과 설계 이력에 기록된 선택 변경이 질적 기록의 영향인지, 같은 시기에
들어온 다른 정보나 자원 제약의 결과인지는 시간 순서만으로 분리되지 않는다. 행위자가
확인한 반사실적 대안도 이미 질적 기록을 본 뒤의 사후 설명일 수 있고, 기록되지 않은
비공식 설득과 선택되지 않은 대안은 출처 대장에 남지 않는다. 따라서 경로를 표시하고
선택을 격리하는 절차만으로는 질적 기록이 없었을 때의 선택을 복원하거나 영향의 범위를
정할 수 없으며, 어떤 독립 대조가 없을 때 동일성·방향·설계 판정을 보류할지 아직
정해지지 않았다.

## 해소 조건

C-003은 질적 기록의 노출과 함께 변한 선택이 다른 정보·제약과 구별되는지, 사후
진술이 아닌 동시적 기록과 독립 대조로 반사실적 대안을 어떻게 검증할지 제시해야 한다.
비공식 경로·선택되지 않은 대안을 관측할 수 없거나 경쟁 원인을 구별할 수 없을 때
영향의 범위를 확정하지 않고 어떤 선택·산출물·판정을 보류하며 불확실성을 어떻게
기록할지도 주장·근거·한계에 밝혀야 한다.
