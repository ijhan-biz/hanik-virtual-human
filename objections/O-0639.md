# O-0639 · 시계별 고유 오류 대조도 공통 보정의 선택을 공유할 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1903
- 해소: 반복 1907에서 C-003의 주장·근거·한계에 고유 오류의 분류자·보정 모델·자극·판정
  기준이 공유하는 시간 기준·관측면·운영자·원자료와 모델 선택 계보를 결과 독립 입력으로
  등록했다. 모델별 고유·공통·분류 불능 오류와 분모 밖 후보를 독립 자료의 양성·음성·모호
  대조 및 자연 운영에서 생성하고, 모델·시계 조합별 잠재 분모·발견 하한·최악·최선 영향·
  미식별 잔여를 산출한다. 제3자 재현 실패나 공통 보정 잔여의 결론 변화 시 해당 시간창과
  의존 연속성을 보류하도록 실제 반영했다.

## 반론

C-003은 공통 드리프트와 시계별 고유 오류를 분리해 대조하고 조합별 잠재 분모와
교정 불능 잔여를 산출하도록 고쳤다. 그러나 고유 오류를 분류하는 교정 표지와
양성·음성·모호 대조의 자극·판정 기준이 같은 시간 기준, 관측면, 운영자 또는
보정 모델을 공유하면, 시계마다 다른 오차처럼 보이는 공통 보정 선택이 반복될 수
있다. 시계 조합을 늘려도 보정 모델의 선택으로 탈락한 후보와 분모 밖 후보를
동시에 놓치면 고유 드리프트의 범위와 최악·최선 영향이 과소평가된다. 따라서
C-003은 고유 오류 분류와 보정 모델의 선택 계보가 공통 원인과 분리되는지, 분리되지
않는 잔여가 시간창의 연속성 결론을 바꾸는지 아직 닫지 못한다.

## 해소 조건

C-003은 고유 오류의 분류자·보정 모델·자극·판정 기준이 공유하는 시간 기준,
관측면·운영자·원자료와 모델 선택 계보를 결과 독립 입력으로 등록해야 한다. 보정
모델별 고유·공통·분류 불능 오류와 분모 밖 후보를 독립 자료의 양성·음성·모호 대조 및
자연 운영에서 생성하고, 모델·시계 조합별 잠재 분모·발견 하한·최악·최선 영향·
미식별 잔여를 산출해야 한다. 제3자가 선택 계보와 산출을 재현하지 못하거나 공통
보정 잔여가 결론을 바꾸면 해당 시간창과 의존하는 연속성을 보류해야 한다.
