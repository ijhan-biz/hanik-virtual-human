# O-0317 · 공유 자원 회계가 결합 꼬리를 중복 없이 제한하는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 1158
- 해소: 반복 1167에서 C-003의 주장·근거·한계에 공유 자원별 식별자·소유자·예약·실제 소비·선점·환불·지연 소비의 사전 고정 회계 단위와 상태 전이·자원 계보를 등록하고, 경계 간 원자적 사건 식별자로 중복 귀속을 제거하며 소유권·권한 전환과 미관측 소비를 별도 기록하도록 실제 반영했다. 입력 경계·재시도·권한 전환의 결합 교란에서 소비 순서·중복·누락·재진입·지연 소비를 검증하고 상태별 최대 사건 수·선행 관계·영향 상한에 미관측 꼬리를 반영하며, 원자료·자원 계보·교란·산출식을 제3자가 재현하지 못하면 해당 꼬리와 의존 결과를 확정하지 않도록 했다.

## 반론

C-003은 입력 도메인·유입률·공유 자원·계약 밖 진입을 독립적으로 봉인하고, 결합
교란에서 누적 자원 경쟁의 상태별 상한을 산출하도록 고쳤다. 그러나 서로 다른 입력
경계가 같은 큐·재시도 예산·권한 토큰을 소비할 때, 자원 사용량을 경계별로 더한 값이
실제 공유 소비인지, 하나의 재진입을 여러 경계의 사건으로 중복 계수한 것인지가
분리되어야 한다. 공유 자원의 예약·선점·환불·지연 소비가 전환 중에 달라지면 각
경계의 상한과 전체 합집합 상한을 모두 만족하는 관측이 있어도 실제 소비 순서와
미관측 꼬리가 달라질 수 있다. 따라서 결합 교란을 실행했다는 사실만으로 공유 자원
회계가 중복·누락 없이 생성·재진입·결합의 상한을 닫는다고 말할 수 없다.

## 해소 조건

C-003은 공유 자원별 식별자·소유·예약·선점·환불·지연 소비의 회계와 경계 간 중복
귀속 규칙을 결과 전에 독립적으로 고정하고, 입력 경계·재시도·권한 전환의 결합에서
소비 순서·중복·누락을 검증해야 한다. 미관측 공유 소비와 재진입의 최악 상한을
상태별 최대 사건 수·선행 관계·영향 상한에 반영하고, 원자료·자원 계보·교란·산출식을
제3자가 재현하지 못하면 해당 꼬리와 의존 결과를 확정하지 말아야 한다.
