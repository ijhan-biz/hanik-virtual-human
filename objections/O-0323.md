# O-0323 · 비교한 상태 전이가 실제로 같은 상태 공간인가

- 상태: resolved
- 대상: C-003
- 제기: 반복 1191
- 해소: 반복 1202에서 C-003의 주장·근거·한계에 주입과 자연 사건의 상태 식별자·해상도·초기 상태·전이 라벨과 두 상태 공간의 대응 규칙·대응 불능 상태 처리 기준을 결과 전에 고정하고 독립 기준 자료에서 검증하도록 실제로 반영했다. 공통 상태·시간창별 대응 기회뿐 아니라 주입 전용·자연 전용 기회를 각각 분모에 포함해 포착률·누락률·검출 한계의 최악 상한을 산출하며, 대응·전이·분모·원자료·계보·산출식을 제3자가 재현하지 못하면 해당 운반성과 의존 결과를 확정하지 않도록 했다.

## 반론

C-003은 교정 주입이 바꾸는 큐 점유·부하·재시도 예산·선택·권한·경계 상태를 등록하고,
주입 전후의 상태 전이와 자연 사건의 동일 상태 전이를 별도 기준 자료로 비교하도록 고쳤다.
또한 주입으로만 생기는 경로와 자연 사건에만 나타나는 경로를 잠재 기회 분모에 넣어
공통 상태·시간창별 포착률·누락률·검출 한계의 최악 상한을 계산하도록 했다. 그러나
주입과 자연 사건의 상태 표지가 서로 다른 해상도·식별자·초기 상태를 사용하거나, 한쪽에서만
도달 가능한 상태를 같은 상태로 매핑하면, '동일 상태 전이'라는 비교 자체가 허위의 공통
지지를 만든다. 반대로 상태가 실제로 같다는 대응 규칙을 엄격히 요구하면 공통 상태가
없어져 최악 상한이 공집합에 대한 계산이 될 수 있다. 따라서 경로를 분모에 넣고 자료를
재현하는 것만으로는 두 과정의 상태 공간 대응과 비교 가능한 기회가 정당화되지 않는다.

## 해소 조건

C-003은 주입과 자연 사건의 상태 식별자·해상도·초기 상태·전이 라벨을 결과 전에 고정하고,
두 상태 공간의 대응 규칙과 대응 불능 상태의 처리 기준을 독립 기준 자료에서 검증해야 한다.
공통 상태·시간창별로 대응된 기회와 대응되지 않는 주입 전용·자연 전용 기회를 각각 분모에
포함해 포착률·누락률·검출 한계의 최악 상한을 산출하고, 대응 규칙·상태 전이·분모·원자료·
계보·산출식을 제3자가 재현하지 못하면 해당 운반성과 의존 결과를 확정하지 않아야 한다.
