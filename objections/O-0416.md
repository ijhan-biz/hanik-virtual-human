# O-0416 · 외부 상태 계보의 재현도 공급자 내부 경쟁 원인을 식별하지 못한다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1393
- 해소: 반복 1394에서 C-003의 주장·근거·한계에 외부 공급자의 중복 수신·경쟁 요청·정책 갱신·재고·권한 상태가 외부 승인·거부·예약·회수 전환을 함께 바꾸는 경로를 내부 계보와 분리해 결과 전에 고정하고, 공급자 내부 원인 후보와 외부 전환의 교차 실행 기회를 자연 사건·독립 주입·음성 대조에서 각각 검출하도록 실제 반영했다. 공급자 기록에 없는 경쟁 행위자·정책·재고·권한 경계와 내부 기록면에 공통인 누락을 별도 검사하고, 후보별 잠재 기회 분모·누락·영향 상한·계보를 외부 상태 전환 및 내부 기록면과 분리해 제3자가 같은 입력으로 재현하지 못하면 공급자 내부 원인·중복 수신 귀속과 이에 의존하는 서사적 연속성을 확정하지 않도록 명시했다.

## 반론

C-003은 내부 전환과 실제 적용·회수·승인·거부·예약 취소·권한 변경을 일으키는
외부 전환 사이의 인과 규칙을 고정하고, 공급자·예약·권한·지연 반영 경계의 공통
누락과 외부 전환별 분모·계보를 내부 기록면과 분리하도록 고쳤다. 그러나 외부
공급자가 같은 요청을 중복 수신하거나 다른 행위자의 요청과 경쟁하는 동안 공급자
내부의 순서·정책·재고·권한 상태가 바뀌면, 외부 전환 계보에 승인·거부나 예약
변경은 남아도 어느 내부 재시도 또는 경쟁 요청이 그 결정을 일으켰는지는 여전히
식별되지 않을 수 있다. 외부 상태의 전후를 재현하는 것과 외부 상태를 만든 공급자
내부 원인을 재현하는 것은 다르다.

자연 사건·독립 주입·음성 대조를 각각 분리하고 외부 전환별 잠재 기회 분모를 세어도,
공급자 내부의 비공개 경쟁 행위자·정책 갱신·재고·권한 판정이 모든 자료와 공통이면
같은 외부 부작용을 만든 원인 후보가 함께 사라질 수 있다. 따라서 제3자가 내부와
외부 계보를 같은 입력으로 재생해도 공급자 내부 경쟁 경로와 중복 수신의 귀속,
그에 의존하는 서사적 연속성을 확정할 수 없다.

## 해소 조건

C-003은 외부 공급자 내부의 중복 수신·경쟁 요청·정책 갱신·재고·권한 상태가 외부
승인·거부·예약·회수 전환을 함께 바꾸는 경로를 내부 계보와 별도로 결과 전에
고정해야 한다. 공급자 내부 원인 후보와 외부 전환의 교차 기회를 자연 사건·독립
주입·음성 대조에서 각각 검출하고, 공급자 내부 기록으로 관측되지 않는 경쟁 행위자·
정책·재고·권한 경계와 공통 누락을 별도 검사해야 한다. 후보별 잠재 기회 분모·누락·
영향 상한·계보를 외부 상태 전환 및 내부 기록면과 분리해 제3자가 같은 입력으로
재현하지 못하면 공급자 내부 원인·중복 수신 귀속과 이에 의존하는 서사적 연속성을
확정해서는 안 된다.
