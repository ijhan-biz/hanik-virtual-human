# O-0562 · 조합 생성 언어가 실제 의미 공간의 폐쇄를 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1616
- 해소: 반복 1619에서 C-003의 주장·근거·한계에 생성 언어가 보존해야 할 상태·계보·순서·재진입 의미와 표현 불능 잔여 및 조합별 폐쇄·종료 규칙을 결과 독립 입력으로 사전 등록하도록 실제 반영했다. 독립 자료와 양성·음성 대조에서 동일 의미의 상이한 표현·상이한 의미의 동일 표현·문법 밖 이력 조합을 각각 검출하고, 표현·의미 대응별 잠재 분모·발견 하한·최악·최선 영향·보류 전파를 산출하며, 의미 보존·잔여 분류·폐쇄의 제3자 재현 실패나 표현 불능 잔여의 결론 변화가 있으면 해당 조합의 운반 자격과 연속성 판정을 보류한다.

## 반론

C-003은 동시성·순서·재진입 조합을 표현하는 생성 언어와 조합별 폐쇄·종료 규칙을
결과 독립 입력으로 등록하고, 독립 자료와 양성·음성 대조에서 등록·미등록 조합 및
그 조합이 만든 지연·연쇄를 분리해 검출하도록 고쳤다. 그러나 생성 언어가 표현하는
조합은 유한한 문법과 사전 정한 상태·시간 범위에 의존한다. 공급자별 선형화, 스케줄러의
비결정적 선택, 재진입 식별자의 이력과 같은 의미가 문법의 서로 다른 표현으로 합쳐지거나
문법 밖의 상태 기억으로 남으면, 조합을 생성했다는 사실과 실제 실행 의미를 모두
열거했다는 사실이 같지 않다. 독립 자료와 양성·음성 대조가 등록·미등록 문자열과
관측된 지연·연쇄를 구별해도, 표현되지 않은 의미 보존 실패와 무한히 증가하는 이력
조합의 잠재 분모·영향을 검출하지 못할 수 있다. 따라서 생성 언어·폐쇄 규칙의 제3자
재현만으로는 조합 공간이 서사적 연속성에 필요한 의미 상태를 닫았다고 확정할 수 없다.

## 해소 조건

C-003은 생성 언어가 보존해야 할 상태·계보·순서·재진입 의미와 표현 불능 잔여를
결과 독립 입력으로 사전 등록하고, 독립 자료와 양성·음성 대조에서 동일 의미의
상이한 표현, 상이한 의미의 동일 표현, 문법 밖 이력 조합을 각각 검출해야 한다.
표현·의미 대응별 잠재 분모·발견 하한·최악·최선 영향·보류 전파를 산출하고, 의미
보존·잔여 분류·폐쇄를 제3자가 재현하지 못하거나 표현 불능 잔여가 결론을 바꾸면
해당 조합의 운반 자격과 연속성 판정을 보류해야 한다.
