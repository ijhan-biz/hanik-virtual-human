# O-0404 · 정책 공간 밖 탐색도 적응 의미의 운반을 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1381
- 해소: 반복 1382에서 C-003의 주장·근거·한계에 정책 항목의 의미·우선순위·적용 대상·충돌 해결 규칙 버전과 변경 계보를 상태 서명으로 포함하고, 같은 항목의 의미 재해석을 새 항목·경계 생성과 분리해 자연 사건·독립 주입에서 각각 검출하도록 실제 반영했다. 정책 의미와 노출·권한·시간창의 공통 지지·운반 조건을 별도로 검증하고 의미 변경·미포착 전환의 잠재 기회 분모·누락·영향 상한·회수 계보를 결과와 분리해 산출하며, 제3자가 상태 서명·운반·종료 기준과 산출식을 재현하지 못하면 경계·결합·인과 귀속·의존 판정을 확정하지 않도록 명시했다.

## 반론

C-003은 등록된 정책 공간 밖에서 분류·목록의 표현 범위를 바꾸거나 새 경계·중재
조합을 만드는 경로를 별도 탐색하고, 상태·시간창·순서·결합 범위와 종료 규칙,
미탐색 조합의 분모·누락·영향 상한·회수 계보를 등록 결과와 분리하도록 고쳤다.
또한 목록의 분류 변경과 새 경계 생성을 별도 자연 사건과 독립 주입에서 각각
포착하는지 확인하도록 했다. 그러나 정책 적응은 조합을 추가하는 것만이 아니라
기존 항목의 의미, 우선순위, 적용 대상, 충돌 해결 규칙을 바꿀 수 있다. 같은
정책 변수와 상태 서명을 탐색해도 이 의미 변화가 동일한 이름의 항목에 흡수되면
새 조합이나 새 경계로 분류되지 않을 수 있다.

독립 주입이 분류 변경과 새 경계를 포착했다는 사실도 자연 운영에서 같은 의미가
보존된다는 것을 보장하지 않는다. 주입은 정책을 관찰하기 위해 입력·권한·시간을
의도적으로 바꾸므로 적응 정책의 우선순위나 충돌 해결을 자연 사건과 다르게
활성화할 수 있고, 자연 운영에서만 나타나는 의미 재해석은 포착하지 못할 수 있다.
따라서 정책 공간·탐색 범위·종료와 산출식을 제3자가 재현해도, 항목 의미의 변경과
주입에서 자연 운영으로의 운반이 검증되지 않으면 경계·결합·인과 귀속을 확정하는
것은 여전히 목록의 이름과 의미를 동일시하는 순환이다.

## 해소 조건

C-003은 정책 적응 탐색에서 항목 이름뿐 아니라 의미·우선순위·적용 대상·충돌 해결
규칙의 버전을 상태로 표현하고, 같은 항목의 의미 재해석과 새 항목·경계 생성을
분리해 독립적으로 검출해야 한다. 자연 사건과 독립 주입 사이에서 정책 의미,
노출·권한·시간창의 공통 지지와 운반 조건을 별도로 검증하고, 의미 변경과 미포착
정책 전환의 잠재 기회 분모·누락·영향 상한·회수 계보를 결과와 분리해 산출해야
한다. 제3자가 같은 입력으로 의미 상태, 운반·종료 기준과 산출식을 재현하지
못하면 해당 경계·결합·인과 귀속·의존 판정을 확정해서는 안 된다.
