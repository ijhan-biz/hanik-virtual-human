# O-0842 · 해상도별 범위의 교차가 공동 결합을 보장하지 않을 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2764
- 해소: 반복 2772에서 C-003의 주장·근거·한계에 해상도·체류 측정·재진입 코딩별 범위가 동일 잠재 경로에서 공동 실현되는지 판정하는 결과 독립 규칙을 사전 봉인하고, 코드 간 공동 지지·잠재 분모·전이·운반 가중의 결합 범위를 독립 대조·자연 계보에서 교차하거나 부분식별하도록 실제 반영했다. 공동 결합을 식별하지 못하거나 결합 최악·최선 범위가 결론을 바꾸면 해당 전이·운반·귀속·계보·연속성을 보류한다.

## 반론

C-003은 유한 이력 절단이 합치는 잠재 과거를 해상도·체류 측정·재진입 코딩별로
열거하고, 각 공동 분모·전이 범위·운반 가중의 최악·최선을 독립 대조와 자연 계보에서
교차하거나 부분식별하도록 고쳤다. 그러나 각 해상도와 코딩에서 얻은 범위가 같은 잠재
경로의 서로 양립 가능한 결합인지, 또는 서로 다른 모집·측정·재진입 선택을 전제로 한
주변 범위인지가 고정되지 않았다. 주변별 최악·최선 범위를 나란히 제시해도 이력 해상도
사이의 공동 지지와 전이·운반 가중의 상관을 놓치면, 실제로 동시에 가능한 범위를 과소평가할
수 있다.

따라서 해상도별 교차와 부분식별만으로는 잠재 경로들의 공동 결합 가능성을 보장할 수 없다.
해상도·체류·재진입 코드 사이의 공동 지지, 일관된 잠재 분모와 결합 범위를 식별하거나
부분식별하지 못하면 해당 전이·운반·귀속·계보·연속성을 확정해서는 안 된다.

## 해소 조건

C-003은 해상도·체류 측정·재진입 코딩별 범위가 동일한 잠재 경로에서 공동으로 실현되는지
판정하는 결과 독립 규칙을 사전 고정하고, 코드 간 공동 지지·잠재 분모·전이·운반 가중의
결합 범위를 독립 대조와 자연 계보에서 교차하거나 부분식별해야 한다. 코드 간 공동 결합을
식별하지 못하거나 최악·최선 범위가 결론을 바꾸면 해당 전이·운반·귀속·계보·연속성을
보류해야 한다.
