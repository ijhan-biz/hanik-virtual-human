# O-0708 · 독립 대조가 결합 분포의 운반 가능성을 보장하지 않을 수 있다

- 상태: resolved
- 대상: C-003
- 제기: 반복 2182
- 해소: 반복 2189에서 C-003의 자료·제3자별 관측 단위, 잠재 분모 생성 규칙, 선택 확률의 조건부 변수와 a_g·c_g 추정량의 동일성·차이를 결과 독립적으로 등록하고, 결합 의존·영·소분모 규칙이 자료 간 교차 대조에서도 같은 추정량과 운반 조건을 겨냥하는지 검증하도록 실제 반영했다. 추정량 또는 운반 조건을 일치시키지 못하거나 차이의 최악·최선 영향이 결론을 바꾸면 해당 비교·계보·귀속·연속성을 보류하도록 했다.

## 반론

C-003은 결합 의존·시간창 반복·관측률 선택·영분모를 결과 독립 근거로 등록하고, 의존
구조가 다른 독립 자료와 제3자 대조에서 분모 처리·변환·집계 순서를 교환하도록 고쳤다.
그러나 독립 자료라는 지위와 제3자 재현만으로는 원자료마다 달라지는 관측 단위의 구성,
잠재 분모의 생성 규칙, 선택 확률의 조건부 구조가 같은 결합 분포를 겨냥한다는 것을
보장하지 않는다. 한 자료에서 영분모를 보수적으로 처리한 규칙이 다른 자료에서는
소분모로 관측되거나, 재사용 상관을 제거한 집계가 실제 계보에서는 선택 이후의 상관을
지워버릴 수 있다. 이때 순서 교환으로 얻은 구간이 재현되어도 서로 다른 추정량을 비교한
것일 뿐이며, 결론을 바꾸는 운반 실패가 독립성 검증의 바깥에 남는다.

## 해소 조건

C-003은 자료·제3자별 관측 단위, 잠재 분모 생성, 선택 확률의 조건부 변수와 추정량의
동일성·차이를 결과 독립적으로 등록하고, 결합 의존·영·소분모 규칙을 자료 간 교차
대조에서 운반 가능한 형태로 검증해야 한다. 추정량 또는 운반 조건을 일치시키지 못하거나
그 차이의 최악·최선 영향이 결론을 바꾸면 해당 비교와 계보·귀속·연속성을 보류해야 한다.
