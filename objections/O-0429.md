# O-0429 · 적용 순서 계보도 숨은 원자화 경계를 보장하지 않는다

- 상태: resolved
- 대상: C-003
- 제기: 반복 1410
- 해소: 반복 1412에서 C-003의 주장·근거·한계에 저장소·작업자·공급자별 원자성·선형화 지점과 부분 커밋·보상·캐시 반영·재시도·재진입 경계를 결과 전에 분해해 식별하고, 실제 상태 변경 순서와 최종 관측·확인 순서의 차이를 경계별 독립 자료와 내부 상태 교란에서 검출하도록 실제 반영했다. 경계별 미관측 중간 상태의 잠재 기회 분모·최대 지연·순서 불확실성·영향 상한과 적용 순서로 운반되는 조건을 별도 계보로 산출하며, 제3자가 같은 입력으로 원자성·귀속·상한을 재현하지 못하면 적용 순서에 의존하는 연속성·책임·완전성을 인정하지 않도록 명시했다.

## 반론

C-003은 공통 경계별 실제 생성·적용 순서와 관측·확인 순서를 분리하고, 적용 순서로
운반되는 조건을 별도 계보에 남기도록 고쳤다. 그러나 적용 순서 자체가 여러 저장소·
작업자·공급자에 걸친 부분 커밋, 재시도, 보상, 캐시 반영을 하나의 사건으로 원자화해
기록한다면, 계보는 관측된 최종 적용 순서만 보존하고 실제 상태가 바뀐 내부 순서를
잃을 수 있다.

순서 교란이 큐나 로그 경계에만 도달하고 부분 커밋·보상 경계에는 도달하지 않으면,
독립 자료가 같은 최종 상태와 적용 순서를 재현해도 중간 상태가 다른 선행 관계를
검출하지 못한다. 따라서 적용 순서로 운반되는 조건의 원자성, 부분 커밋·보상·캐시
반영의 잠재 기회와 영향 상한, 그리고 그 순서가 서사적 이유·책임·수정의 실제 상태
변화를 대표한다는 근거는 아직 보장되지 않는다.

## 해소 조건

C-003은 적용 순서를 구성하는 저장소·작업자·공급자별 원자성·선형화·부분 커밋·보상·
캐시 반영·재시도 경계를 결과 전에 식별하고, 실제 상태 변경 순서와 최종 관측·확인
순서의 차이를 경계별 독립 자료와 내부 상태 교란에서 검출해야 한다. 각 경계의
미관측 중간 상태 잠재 기회 분모·최대 지연·순서 불확실성·영향 상한과 서사적 조건으로
운반되는 경로를 별도 계보로 산출하고, 제3자가 같은 입력으로 원자성·귀속·상한을
재현하지 못하면 적용 순서에 의존하는 연속성·책임·완전성을 확정해서는 안 된다.
