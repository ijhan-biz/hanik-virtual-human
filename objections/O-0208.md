# O-0208 · 독립 자산 발견이 무기록 산출물의 사용을 놓치지 않는가

- 상태: resolved
- 대상: C-003
- 제기: 반복 0732
- 해소: 반복 0734에서 C-003에 오프라인 장치·작업공간·화면·클립보드·메모리와 기록되지 않은 해석·전달을 사전 봉인한 현장 표본으로 독립 기록자들이 직접 대조하고, 수신자·후속 판정자의 사용 흔적과 의미 보존 변환을 교차 확인하는 절차를 도입했다. 복수 지문과 근접 변형·동일 지문 대조군으로 충돌과 동일성을 분리 시험하며, 직접 현장 대조나 독립 수신·사용 증거가 없으면 미발견 자산의 가능한 종류·시간·경로와 그 의존 판정을 보류하고, 원자료부터 사용처까지를 직접 덮는 새 계보·독립 증거가 있을 때만 회수·재검증 후 해제하도록 주장·근거·한계에 반영했다.

## 반론

C-003은 등록 목록과 다른 저장소·권한·전달 경계의 흔적과 산출물 지문을 대조해
목록 밖 파생물·복제본·수동 해석·외부 전달을 찾도록 고쳤다. 그러나 오프라인 장치,
일시적인 메모리 산출물, 기록되지 않은 화면 해석처럼 생성·사용 흔적이 남지 않는
경로는 별도 저장소와 접근 로그의 탐색으로도 포착되지 않는다. 내용이 조금 변한
복제본은 지문 충돌 기준을 피할 수 있고, 여러 산출물이 같은 지문을 공유하면 발견된
자산과 실제 사용된 자산을 구분할 수도 없다. 따라서 발견표가 독립적이어도 무기록
산출물의 존재와 사용 여부를 판정할 수 없는 범위, 그 범위에 의존하는 이미 해제한
판정의 회수 기준이 아직 충분히 정해지지 않았다.

## 해소 조건

C-003은 저장소·권한·전달 경계에 흔적을 남기지 않는 오프라인·일시적 산출물과
변형·지문 충돌을 찾을 독립적인 현장 대조 또는 사용 흔적 검사를 사전에 제시해야
한다. 그 검사로도 존재·사용 여부를 판정할 수 없으면 미발견 산출물의 가능한 범위와
그에 의존하는 기해제 판정까지 보류하고, 어떤 독립 증거가 직접 덮을 때만 회수·해제할
수 있는지 밝혀야 한다.
